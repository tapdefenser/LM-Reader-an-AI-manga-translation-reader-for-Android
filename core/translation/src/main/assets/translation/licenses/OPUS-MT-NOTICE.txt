OPUS-MT optional translation models

Model authors/project: Helsinki-NLP and OPUS-MT contributors.
https://github.com/Helsinki-NLP/OPUS-MT-train
https://huggingface.co/Helsinki-NLP
Ready ONNX exports: Xenova, https://huggingface.co/Xenova

Model weights and tokenizer files are downloaded on demand, not bundled in
the LM-Reader APK. Each installed package descriptor retains the model
repository, immutable revision (in its version and URLs), hashes and license
declared by the upstream or export model card. Model licenses are independent
of Bergamot, Marian, SentencePiece and ONNX Runtime code licenses.

The default catalog accepts models declaring Apache-2.0 or CC-BY-4.0.
Original terms:
https://www.apache.org/licenses/LICENSE-2.0
https://creativecommons.org/licenses/by/4.0/legalcode

Attribution: Helsinki-NLP/OPUS-MT (original model), Xenova (ONNX export).
LM-Reader uses the quantized ONNX export and performs local greedy decoding;
it does not modify or retrain downloaded weights. For model-specific training
data, contributors, limitations and attribution, consult its original model
card: https://huggingface.co/Helsinki-NLP/<opus-mt-source-target> .
The exact export repository and license are displayed on each package card.
