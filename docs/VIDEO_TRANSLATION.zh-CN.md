# 视频图库与翻译（改造中）

本文描述当前工作区的新实现，设备验收与 Release 交付仍在进行。旧播放器的历史记录见[原执行进度](plans/2026-10-20-execution-progress.zh-CN.md)，不能作为新实现的完成证明。当前证据与待验收项见[改造实施记录](plans/2026-10-21-redesign-implementation.zh-CN.md)。

主菜单选择“图片 / 视频”，首页底部圆角分段按钮切换“库 / 书架”，图库现简称“库”。重启后保持媒体选择，切换媒体时保留当前集合，各页面的搜索、筛选、排序和滚动位置分别保存。库列出系统媒体库已索引且获授权的视频；部分授权、拒绝授权和暂时不可访问分别显示。发现过程分页查询元数据，不遍历哈希全部文件；打开选项时可按需补查缺失时长和尺寸。开始翻译自动加入视频书架，单纯播放不自动收藏。

点击视频直接打开 Media3 播放器。点击显示或隐藏控制栏，中心双击播放/暂停，两侧双击前后十秒，长按临时两倍速，松开恢复；滑动调时间、窗口亮度或媒体音量。锁定、播放列表、速度、音轨、循环/随机和系统 PiP 分别提供入口。播放列表固定为点击时的筛选排序；大列表通过持久快照令牌传递，避免把全部条目放入 Binder。普通退出暂停播放；后台翻译由任务宿主推进。

## 翻译与字幕来源

翻译选项选择源/目标语言、仅画面/仅字幕/画面与字幕、对应工作流、时间范围和字幕来源。画面默认一秒一个采样位置，提供 0.5/1/2/5 fps，提交前显示采样量。采样由媒体时间驱动，与播放、拖动或倍速分开，最多两份在途画面；不承诺低采样率能发现短暂出现的全部文字。

字幕来源可选择外部 SRT、支持的容器文本轨、本地 ASR 或明确配置的音频 API。图形字幕和不支持的文本格式会报告能力限制。文字 API 配置不会自动授权音频上传，纯本地路线不需要 API。

本地语音模型位于“设置 → API 与翻译引擎 → 本地 ASR 模型”，提供模型目录、下载/导入、完整摘要校验、选择和取消管理。当前接入 whisper.cpp CPU 运行时及 Tiny/Base 目录；模型权重按用户操作获取，不随应用或成果包自动传送。实际语言质量、峰值内存和 ARM 性能仍待实测。原生构建前运行 `python tools/fetch_asr_sources.py` 准备固定版本源码。

画面、字幕和 ASR 通过同一持久任务账本与资源准入执行，各分支保留进度、暂停和恢复点。一支失败保留另一支成果；本页/本画面任务优先取得下一份空闲资源，不强断 native 调用或为插队重发在途付费请求。缺模型、授权或系统后台条件时保留任务并显示补齐入口；远端结果未知的请求需要明确核对后重试。

## 编辑与成果

“编辑译文”编辑画面气泡：文本、几何、字体及每个区域自己的时间范围。字幕从播放器独立入口进入，支持原文/译文、起止时间、前后条目跳转、增删、撤销及样式。智能颜色采样原画面的字幕覆盖区，不能触发重新翻译。人工修改和删除有 revision 保护，迟到机器结果需通过发布屏障。

导出先提供译文/双语 SRT 和可恢复的画面与字幕成果包；成果包校验原视频摘要、区域身份和版本，导入时保留本机人工修订。SRT 不保存字体和颜色，样式保存在成果包。带译文的新 MP4 仍是独立范围。

## 数据与兼容

原视频始终只保留引用，不复制或改写；原有 SAF 项目迁入视频书架，旧成果文件和人工标记继续保留。系统索引、书架关系、任务和时间索引位于新增的 `media-work.db`，漫画数据库不因视频改造重写。正式成果继续使用有摘要与原子替换保护的文件；解码帧、缩略图、预处理和音频片段属于可重建缓存。

首次翻译或恢复成果时按需核对源内容；权限撤回、存储卡暂离不当作用户删除。重新定位允许明确建立新源版本，旧源成果仍保留。清译文、恢复备份和编辑共用写入协调，先停止对应写入者。

视频备份覆盖新表、偏好、任务恢复元数据和正式成果，不包含原视频、模型与大量中间帧。成果包不包含凭据；应用完整备份仍沿用既有“包含 API 密钥”的显式选项。跨设备恢复后先重新定位或授权，不能把另一设备的 MediaStore ID 直接认作相同文件。

## 画面翻译

在“翻译设置”选择源/目标语言代码和图像工作流，例如 `ja` → `zh-Hans`。本地流程使用已有 SEG、OCR 和机翻；API 流程保留各节点自己的 API 绑定。需要 API 的参考流程先在“翻译工作流”复制并绑定配置。缺模型或绑定时显示具体步骤的错误，补齐后返回原视频再次开始，不需要重新导入。

可以暂停后“翻译当前画面”，也可以开启“连续画面翻译”。播放原视频的同时叠加气泡轮廓或游离文字区域；“画面遮罩”和“字幕”分别开关。支持跳转、0.5/1/1.5/2 倍速和横竖屏布局。译文来不及时显示处理状态，保持原画面。

播放器只从解码表面获取原画面，不采集叠加的译文。分析帧最长边限制为 1280，成果保存分析坐标，绘制时按视频显示区域缩放并保留黑边。每个会话最多一个在途帧工作流，取消的 native 调用返回前不启动下一帧，避免快速跳转积累任务。

每份画面成果记录原视频身份、采样播放时间、已验证区间、任务摘要和版本。只保存区域、文字及微型原文笔画样本，不长期保存完整帧。使用已有区域匹配逻辑检查当前画面的原文笔画；跳转立即清除遮罩，旧请求不得直接贴到新位置。重新打开后仍需匹配当前源画面，不能仅凭时间或文件存在复用。采样与匹配属于保守的间歇分析，不承诺逐帧或所有设备实时翻译。

## 字幕翻译与校对

先导入 UTF-8 SRT，支持 BOM、常见换行、毫秒逗号/小数点及重叠条目。错误指出行号，不跳过非法条目或把它们错配到其他时间；字幕超出已知视频时长时拒绝导入。首版限制 4 MiB、20,000 条。

在“翻译设置”选择“字幕：本地机翻”或复制、绑定后的“字幕：API 翻译”。字幕使用独立的 `TIMED_TEXT` 输入场景，复用文本翻译、API、上下文及列表等块，不要求漫画结构、SEG 或假图片。现有未注明场景的工作流继续按 `IMAGE` 读取。字幕流程返回完整条目列表；平台检查条目身份、原文与时间均未被改变。

逐条保存字幕进度，取消或退出后可继续翻译空白条目；已有译文和人工校对保留。切换语言或相关流程后，原译文仍在并提示配置变化。需要重译时先导出，再明确清空字幕译文；替换字幕轨与清空译文分别确认。

播放器支持原文、译文、双语显示；“校对字幕”可改译文、跳转到条目及调整 ±1 小时内的偏移。保存与分享采用点击时捕获的字幕和偏移，输出当前显示模式的 SRT。分享文件通过系统分享面板授予读取权限，临时文件至少保留七天后才在后续分享时清理。首版不生成 MP4 输出。

## 数据与兼容

- 外部原视频：应用仅保存引用与摘要，移除视频条目、清缓存均不删除原文件。
- 正式成果：`files/videos/` 中的元数据、区域译文、原文笔画样本、字幕校对与观看进度，按同一视频 ID 归属，采用原子文件替换。人工成果不因缓存预算被逐出。
- 可重建缓存：`files/video-analysis-cache/<视频 ID>/`，每视频预算 32 MiB，文件归属与正式成果分开。视频数据入口显示占用；清理前停止会话并等待 native 工作与发布完成。
- 模型：沿用共享模型管理，视频移除或清缓存不卸载模型；停止会话释放自己的运行资源引用。
- 备份：复用应用现有备份、校验及回滚，加入视频正式数据，不包含原视频和分析缓存。恢复后重新核对源文件授权/内容。旧备份不含视频区段时保留本机视频数据；包含视频的新备份需使用支持视频的版本恢复。

声音转写、离线 ASR 和语音 API 尚未接入；当前声音字幕由 SRT 导入。片单/收藏、完整回收站和全局空间管理仍按最终计划另行推进。实测范围、失败记录和未验证项见[执行进度](plans/2026-10-20-execution-progress.zh-CN.md)。
