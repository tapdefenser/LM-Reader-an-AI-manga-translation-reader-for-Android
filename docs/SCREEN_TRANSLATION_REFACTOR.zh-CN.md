# 屏幕翻译重构与验证

## 视频模式双帧流水线

- 截图只在同时满足以下条件时执行：最新帧的全部选区完成 SEG、截图延时到点、双帧缓冲有空位、缓存预算允许。完成 SEG 即可准备下一帧，不等待 OCR；各选区独立处理，单个选区失败不跳过其他选区。
- 缓冲最多保留两帧，按截图顺序退出。第二帧即使因复用而提前完成，也必须等第一帧回填结束后才能释放名额，不能绕过阻塞中的第一帧不断抓图。
- 延时从前一帧 SEG 完成时开始，与新一帧的 SEG 并行。例如 A 在 100ms 完成 SEG 后截 B，延时为 200ms：B 在 150ms 完成 SEG，则 C 最早在 300ms 截图；B 在 500ms 完成 SEG，则不再额外等 200ms。两种情况都必须先有缓冲空位。
- 视频不再按整幅画面的灰度差异跳过 SEG。每帧 SEG 后比较对应区域的轮廓、原文字纹理与位置，使用独立的「视频 SEG 区域相似度」，默认 60。相似分数必须超过阈值才复用；100 表示不复用。新候选从后续 OCR/翻译中移除，整页输入也屏蔽对应旧文字。
- 复用保留原气泡身份和已完成译文，并把绘制位置移到新帧。原气泡的翻译尚未完成时，后到的结果仍回填到其最新位置。旧帧译文在新气泡就绪前继续显示；只有空工作流完成而复用译文仍未就绪时，不提前清掉旧文本。停止、切换场景或重配置会清空这条复用链，防止旧结果重新出现。

## 已实现的行为

| 项目 | 当前实现 |
| --- | --- |
| 资源 | 仅游离文字覆盖气泡内外全部文字，DET 检测后以文字框绘制；跳过气泡 SEG 模型。共享漫画工作流也传递相同范围。OCR、机翻按工作流需要加载。 |
| 默认值 | 屏幕范围为仅游离文字；视频识别全屏；始终预处理下一画面，移除开关。已有范围与视频区域配置保留。 |
| 调度 | 视频采用上面的 SEG 双帧流水线；浏览保留原有整张 SEG/DET、OCR 就绪与提交间隔门槛。两者占满时都等待空位与缓存预算。 |
| 手动 | 译文绘制及按钮恢复后建立检测基线；后续来源、遮罩可见规则一致。检测变化后延迟清除，不自动翻下一页。 |
| 浏览 | 光流连续运行，识别独立等待画面稳定。8×8 均匀角点、稀疏光流和三参数 RANSAC 分离移动内容与固定控件；支持同时平移、放大、缩小，累计缩放平滑保留细小缩放。 |
| 整体蒙版 | 只增强跟踪小图，保留有效区域内完整亮度范围，局部光流补偿增益／偏移；运动确认与逐对象模板使用归一化相关性，注册置信度考虑缩放后细线条的抗锯齿差异。原图和 OCR 不做这项增强。 |
| 逐气泡 | 设置提供「整屏／整屏＋逐气泡」，默认后者，包含游离文字框。按缩放后的原图纹理验证移动位置与原位置；两次不同有效帧均严重失配才删除，可见性不足时保留。 |
| 新区与裁块合并 | 普通 SEG/DET 只读取实际新增裁块，按同一稳定干净截图中的光流位置排除已有原文（包括翻译中）。先根据新检测文字与旧文字的相交／距离建组，默认间距 8 截图像素、设置可调，再从该帧原图恢复完整组重新 SEG/DET，最后才进 OCR。空白条带外接框不触发递归合并；几何与纹理不变的旧区域复用。半出屏旧文字保留完整译文。 |
| 替代与取消 | 最终新遮罩接管背景后，旧区域在独立会话数据库标为已过时并关联新 SEG 参数，保留旧译文到对应新文字逐泡到达。只取消被替代区域的预 OCR 与气泡工作分支；迟到结果不能复活旧遮罩。多次合并转接祖先依赖。空／失败结果保留旧文字；停止浏览或换场景清空会话记录。跟随不逐帧写库。 |
| 遮罩与回填 | 仅浏览模式在 SEG 确定区域后先绘制空遮罩，并立即加入光流。三个模式都接受逐气泡／流式回填，不等整页完成；填文字保留对象已有位姿和跟踪记录。手动、视频不显示空遮罩。 |
| 弹窗 | 浏览模式保留底层窗口的场景身份，弹窗 ID 不直接清空气泡。无障碍暂时只报告弹窗时暂停采样并保留覆盖记录；采样前后检查窗口状态，过渡帧不写入匹配基线。底层可用时排除遮挡区域。应用内菜单用亚像素网格纹理连续性和连续遮挡区域判断，先验证正文运动，避免把固定顶栏／底栏之间的滚动正文误当成遮挡。 |
| 区域方案 | 入口位于模式选择下方；浏览、视频独立应用方案。方案保存横竖屏各最多八个框，弹窗可滚动并提供可拖动滚动条，新建／删除在左下角。编辑器只完成／取消，应用时保存命名方案；删除库条目保留已应用副本。透明编辑任务拦截底层触摸，实际请求编辑方向；没有框为全屏。跟踪、识别、覆盖记录和绘制只处理选区并集，空隙不记成已识别。 |
| 悬浮球旋转 | 等最终屏幕尺寸与可见系统边距稳定后重新贴边，保留左右边和高度比例；半隐藏状态仍能点击。 |
| 采集 | 连续模式强制无障碍。优先验证单应用 MediaProjection 原始流，失败或取消授权使用窗口截图。连续模式不隐藏遮罩。 |
| GPU | GLES 只负责降采样与灰度化；比较 CPU 输出、方向及含调度／同步／回读的耗时，失败或没有收益则回退 CPU。 |
| 视频结果 | 新气泡逐个显示，其余旧文字保留到对应裁块完整结果到达再清理；完整空结果也清除旧字幕。按场景代次与提交序号拒绝迟到旧结果及清理。 |
| 图像与 OCR | 借用截图及一次计算的哈希，不按文字区域反复读图／解码；安全的纯 OCR 提前执行，与机翻重叠。 |
| 缓存 | 已接纳画面完整处理，即使超过预算；保护未发布结果，失败／取消画面及预处理保留重试，死缓存阻塞给出提示。 |

浏览模式仍按原节奏调度。例如间隔 200 ms、总翻译 500 ms：OCR 在 120 ms 完成，等到 200 ms 才取第二张；OCR 在 250 ms 完成，则在就绪后取第二张。两张占满以后等第一张释放槽，再按最后提交时间判断，不额外等完整间隔。匹配同样完成后再取下一帧，不因超过目标帧周期取消计算。

可提前识别的工作流只使用不可变原图／区域图和固定或系统语言。条件 OCR、API 返回值决定的语言、自定义图片引用、提前返回等情况保守维持工作流执行顺序；无法安全预处理时不承诺第二张提前推进。

## 适配边界

连续模式需要 Android 14 及以上公开的干净采集接口。仅窗口截图时系统限制频率，统一使用至少 334 ms 请求间隔，不能实现 30 FPS。单应用流是否可用以实际内容校验为准，不按手机品牌或芯片白名单判断。Android 13 及以下保留手动模式。

GPU 启用依据运行时扩展、硬件缓冲区结果和实测收益；不同 OEM、GPU 驱动及 Android 版本仍需要实体机验证。匹配只支持平移与等比例缩放，纯色、重复纹理和大幅跳转可能无法匹配；场景重置会阻止旧结果落到新页面。

自动化测试使用可与正式包并存的 Debug 包；手机交付使用原签名 Release。使用说明见 [中文指南](USAGE.zh-CN.md#屏幕翻译当前开发版) 与 [英文指南](USAGE.en.md#screen-translation-development-build)。
