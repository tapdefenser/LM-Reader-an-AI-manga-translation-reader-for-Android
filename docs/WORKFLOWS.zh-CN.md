# 猫爪翻译工作流：实现与用户说明

[English](WORKFLOWS.en.md) · [使用指南](USAGE.zh-CN.md)

本文说明原生 Android 工作流编辑器与执行器的当前行为。

## 1. 入口与编辑

主菜单 → 翻译工作流。内置本地机翻及标准翻译、VL 直接翻译、VL 整页直接翻译三种参考模板只读，可查看和复制。参考模板复制后用“为所有请求选择 API”绑定配置，也可逐行单独选配置。新建创建含默认 SEG 的空白结构；可编辑工作流可修改、复制、删除，固定工作流可查看、复制、删除和统一绑定 API。删除时列出引用漫画；已排队任务固定使用原快照。

```text
漫画 {
  每章节 [同步／异步] {
    每页 [同步／异步] {
      SEG：本页图片 → 译文气泡列表
      ＋新增行
    }
    ＋新增行
  }
  ＋新增行
}
＋新增行
```

三个固定结构各保留一个，位置固定。每个作用域只有末尾的新增行。新建空白工作流也默认在每页中放置 SEG。作用域使用连续的圆角底色区块，每进入一层，底色加深并向右缩进，与内部文字对应。每个步骤是独立圆角卡片，各层卡片底色相同。点击任何卡片打开参数抽屉，查看模式下全部参数只读；点同步／异步直接切换。

普通行通过三点菜单上移、下移、移到外层或“移动到…”指定其他作用域／位置，也可复制、删除。移动检查整棵树的作用域，不能把 OCR 搬到气泡变量不存在的位置，也不能移入自己内部；非法移动保留原位置并解释原因。撤销保留最近 50 次结构修改。

右上角三点菜单包含名称与重试、模板、统一 API 绑定、猫爪文本和说明。参数抽屉用横线分隔输入、输出、参数；返回／关闭未保存的步骤时选择保存、放弃或继续编辑。工作流退出也单独检查未保存修改。可以保存草稿，入队和执行前再次校验。修改产生新修订。

“填入模板”提供空白结构、本地机翻、标准翻译、VL 直接翻译、VL 整页直接翻译。替换模板可撤销，参数及顺序仍可修改。“查看猫爪文本”由当前树直接生成完整程序，包含行、嵌套、类型、提示词、变量绑定、输入输出与异步结果收集；可选中文字，编辑后同步更新。可在内置模板的「查看猫爪文本」中查看实际生成的完整示例。

## 2. 行与参数

| 行 | 用途 |
|---|---|
| 新建变量 | 名称、类型、初始值；默认空值。图片、气泡及含图片的记录需引用已有值 |
| = | 把固定值或变量写入兼容的可写变量／字段 |
| SEG | 本页图片→译文气泡列表；检测气泡与文字区域，使用本漫画翻译选项中的提取范围；身份和几何由引擎提供 |
| OCR | 将 SEG 检测出的文字行转为原文文本；同一区域的排版换行按语言连接成连续文本 |
| 本地机翻 | 文本、源语言、目标语言→译文；使用已下载完整路线 |
| API 请求 | 配置、提示词、上下文、图片附件→指定输出变量 |
| API 请求－流式输出 | 返回结构化记录列表；每收到完整一项，按顺序执行内部行，提供当前条目及序号 |
| 按气泡 ID 回填 | 对照／页记录列表或单条记录；按 ID 更新本页原文和译文，保留 SEG 身份及坐标 |
| 按气泡顺序回填 | 含 translation 文本字段的记录或列表；指定从 1 开始的起始序号，按 SEG 气泡顺序回填 |
| 每项 | 遍历列表／字典，声明条目变量；同步／异步；在参数里选择每项完成后的收集值 |
| 如果 | 布尔条件→满足或否则分支 |
| += | 文本新增文本，列表新增一项；可追加到外层声明的列表或文本（含异步子分支），并行追加不保证顺序但不会丢项 |
| 合并列表 | 同类型列表追加到目标列表 |
| 字典匹配替换 | 最长原词优先、大小写敏感、一次匹配；替换结果不会再次匹配 |
| 新增上下文 | 用户消息及可选助手示例，连续多行组成 few-shot |
| 新增译名 | `source / translation` 列表，只填漫画字典中的空缺原词 |

所有列表都提供 `<数字> · 列表名称 · 项数` 候选，表示当前列表长度；空列表为 0，嵌套列表和记录中的列表也支持。项数只读，可作为数字输入或插入模板。`=` 和 `+=` 的输入候选优先显示基本类型值入口：选择 `<数字>值` 或 `<文本>值` 后直接填写数字或字符串；数字支持负数、小数。输入仍须与输出变量或列表条目的类型一致。

同类型操作分组显示。参数直接列出全部可用变量及值选项，横向滑动选择；输入过滤类型，输出还过滤只读字段。变量统一显示“<类型> · 名称”，例如 `<文本> · 源语言`、`<列表<气泡>> · 译文气泡列表`；猫爪文本同样用 `<>` 标记类型。不同类型使用不同颜色，步骤卡片以小字固定显示两行：`In: 输入摘要`、`Out: 输出摘要`。多个变量在同一行排列，过长时省略，点击卡片查看完整参数；普通 API 和流式 API 的输入摘要都只显示“提示词模板”。颜色之外仍保留类型文字。图片作为真实 API 附件发送，不能作为文本序列化；气泡循环中的请求默认自动附带当前项裁图，也可选择其他附件或“不附图”。

每部漫画的“翻译选项 → SEG 提取范围”提供“气泡”“游离文字”“气泡+游离文字”，默认选择两者。气泡内的文字块先归属气泡，再筛选范围，因此“游离文字”不会把气泡内文字重新加入。选择按漫画保存，并写入新任务的设置快照；修改选项不影响已经入队的任务。SEG 积木仍然只接收图片，不增加范围参数，猫爪工作流的保存、复制和导入导出格式不变。

SEG 在三个档位下均检测文字行，并补充气泡外未被气泡分割模型检出的游离文字区域。两类区域统一输出为 `<列表<气泡>>`，每项均包含独立 ID、裁图、原文／译文及区域类型，使用同一个“每项在列表”循环处理。不含 OCR 步骤的视觉 API 工作流也会加载文字检测模型；OCR 步骤复用 SEG 的文字行框，只做文字识别。功能上文字检测属于 SEG，但资源仍计入 OCR，与文字识别共用本地 OCR 的并发上限与加速设置。气泡分割模型继续使用 SEG 的并发和 GPU 设置。队列保留需要的检测模型；不含 OCR 步骤时不加载文字识别模型。

本页每次成功执行 SEG 都重建气泡：替换本页气泡列表，清空本页旧翻译记录、OCR 坐标和裁图缓存，立即更新阅读预览。选择自定义输出列表时，也自动同步本页；零检出得到空列表。新一轮气泡具有新的身份，旧气泡裁图引用不能继续用于 OCR 或 API。SEG 应放在气泡循环之外，以免重建循环正在使用的列表。

粘连气泡的分割框可能覆盖多个文字块。SEG 保留内部文字块，建立独立 ID 和裁图；多个有效掩码连通块分别保留，相邻重叠气泡不再仅凭大框包含关系被删掉。一个气泡只有一个文字框时仍识别完整气泡，避免不完整文字检测裁掉其余行。本地 OCR 和图片 API 使用相同的轮廓隔离，游离文字裁图排除气泡像素。OCR 保留原始行与坐标，向后续猫爪积木输出连续文本：中日文接续，英文和韩文补词间空格；不同区域分别识别和翻译。

输入、输出及提示词的变量选项栏前都有独立搜索框，可按变量名、字段名或类型筛选；类型选择窗口同样支持搜索。筛选不改变已选变量，清空搜索即可恢复全部选项。请求提示词直接使用模板输入框，其上方是可插入变量的横向列表，点击在光标位置插入，例如 `${源语言}`、`${译名字典}`、`${气泡 · ID}`。底层保存稳定变量 ID，改变量名字不破坏引用；手写未绑定占位符会报错。自定义字段名称／类型改变后，应检查并重新选择受影响的字段引用。

## 3. 可用变量与作用域

每个卡片右侧的 `{}` 列出当前作用域可用变量、字段、类型、只读状态，可搜索。容器卡片列出其内部变量，普通卡片列出该行之后可用的变量。表中的英文键用于结构化数据；界面显示中文名称。

| 变量 | 范围 | 字段与规则 |
|---|---|---|
| 漫画 | 漫画内 | `id, name`，只读 |
| 漫画页列表 | 漫画内 | 全部本次任务组页面的轻量引用；用普通每项循环拼出整漫画识别，循环参数关闭保存本页并收集本页记录 |
| 源语言、目标语言 | 漫画内 | 漫画属性，语言代码文本，只读；使用任务快照 |
| 文风 | 漫画内 | 漫画→分类→全局解析的文本，只读 |
| 译名字典 | 漫画内 | 唯一 `原词→译名` 字典，**每次读取最新值**，用新增译名行更新 |
| 本章 | 每章节内 | `id, name, index, records`，只读；每页循环完成后 records 按原页顺序汇总 |
| 本页 | 每页内 | `id, name, number, image, bubbles, records`；bubbles／records 可写 |
| 气泡／自定义循环项 | 对应每项内 | `id, index, image, source, translation, confidence, kind`；气泡只允许改原文和译文 |
| 字典循环项 | 对应每项内 | `key, value` |
| 当前条目、当前条目序号 | 流式 API 内 | 类型由输出列表条目决定；序号从 1 开始，只读，用于顺序回填 |
| 自建变量 | 声明行之后至所属分支结束 | 异步子分支中的父层变量只读，但 `+=`／`合并列表` 可追加到外层列表或文本（在所属帧上加锁，并行不丢项、顺序不定）；同步子分支可修改兼容的可写变量 |

页／章自动对照记录：

```json
{"pageId":"页ID","pageNumber":7,"bubbleId":"气泡ID","source":"图片原文","translation":"对应译文"}
```

记录不包含几何／位图。空白页得到空列表。每项完成后，修改按原序写回气泡列表；API 不能创建气泡身份或坐标。

## 4. 自定义列表与异步收集

「API 请求」和「API 请求－流式输出」的附件都可选 `<图片>` 或 `<列表<图片>>`。新建变量时可直接选图片列表，再用 `+=` 新增气泡／整页图片，或通过循环的「收集到列表」和「每项完成时收集值」收集图片。列表可以声明在外层、在更内层的循环里追加：例如在每页声明图片列表，气泡循环里用 `+=` 把当前气泡裁图塞进去，循环结束后同一个列表就能作为附件发出。选择列表后，同一次请求按列表原顺序发送全部图片，不会额外自动附带当前气泡；张数不限，只受单次请求附件总大小（合计 16 MB Base64）约束。空列表表示不附图。

类型包括文本、数字、布尔、图片、气泡、上下文、字典、列表、自定义记录。列表可设置条目类型；记录逐字段设置名称和类型。可嵌套，UI 最多四层，存储校验最多八层。

例如“对照列表”的条目为 `{source:文本,translation:文本}`。API 可直接输出该列表；也可用下述结构构造：

```text
每页 {
  新建 对照列表：列表〈source:文本, translation:文本〉
  SEG → 本页.译文气泡列表
  每 气泡 在 本页.译文气泡列表 [异步]，收集 {source:气泡.原文, translation:气泡.译文} → 对照列表 {
    OCR → 气泡.原文
    本地机翻 → 气泡.译文
  }
  # 后续行可将对照列表交给 API
}
```

异步分支可以用 `+=`／`合并列表` 追加到外层声明的列表或文本：追加在所属帧上加锁，并行分支不会丢项，但顺序不确定。需要严格按输入顺序时，改用每项参数里的「收集到列表」和「每项完成时收集值」；开启「合并每项列表」时，收集值应为同类型列表，展开合并，无需返回结果行。直接改写（`=` 赋值、按 ID 或顺序回填）仍只允许当前分支／同步循环。固定每页循环自动提供整章对照。

图片列表保存轻量引用。当前页位图保留并计入 SEG 缓存预算，普通翻译页完成且所有图片使用者结束后释放。整漫画预处理完成的位图继续保留；新页需要空间时只逐出已完成且无人使用的位图，仍保留原文、坐标、源指纹和尺寸，全文文本回填无需再次解码。后续图片请求引用被逐出的图时才按需解码原图。多个异步分支引用同一张图片时共享位图。附件在内存中编码，不生成翻译 PNG。

## 5. 同步、异步、队列与资源

行顺序执行，请求行等待自己的结果。异步指不同循环项同时工作，后续行仍等待该循环全部分支完成。因此每页之后能处理整章记录，每章节之后等待本次任务组章节完成。

参数抽屉的“最大并行数”只对异步模块生效：设为自动时跟随引擎上限，设为 1～8 时本模块最多同时处理这么多项，实际并行度不会超过引擎上限。同步模块不显示此参数，但仍保留已保存的数值。

同步循环按输入顺序处理。异步循环使用最多 8 个工作协程领取引用，全局最多 8 个活动页，不为全漫画一次创建所有位图。实际缓存页数受 SEG 的 MB 设置限制；满时新页等待，已有页保留图片直到完成。SEG／OCR 使用各自实例池，当前 Bergamot native 机翻仍串行。

边界为漫画。同漫画相同任务快照的章节可异步；不同快照分组运行，资源按该漫画待执行快照取合集。换漫画前结束旧分支，共有模型保留，多余模型卸载。全部暂停或没有剩余任务时全部卸载。

排序改变后，完成当前显示的页，停止其他旧分支并重选队首。新队首先跳过已有缓存页，第一张未翻译页先完成，再恢复该任务组的异步调度，防止旧章节的后页再次抢先占用资源；队首全部有缓存时，完成该章校验后放行。正常运行不按章节号串行等待。取消／清除本页在保存锁内检查任务身份和排除状态，晚到结果不能复活已清除页。已完成页按源指纹复用，恢复不重复推理或重复刷新通知。

队列显示实际 SEG、OCR、API 活动请求数，不显示当前行名称／阶段。文字检测活动计入 OCR；等待许可及空闲已加载模型不计入活动数。尚无逐分支调试面板或断点。

三点菜单分别提供“全部开始”和“全部暂停”，任何状态都可使用。全部开始解除全局暂停，将 PAUSED、FAILED、INTERRUPTED 恢复为 PENDING 并清空错误；保留任务快照、页排除和已完成页，DONE 与 CANCELLED 不重跑。后点击的全部暂停优先于尚未完成的开始命令。

“全文速译”已从内置模板和“填入模板”菜单移除。已有用户副本及队列快照仍按保存的程序运行。

“VL 整页直接翻译”先执行 SEG，按顺序收集本页全部气泡／游离文字裁图，再一次发送给视觉 API。流式列表每项仅包含 `source`、`translation`，按当前条目序号逐项回填，无文字裁图返回两个空字符串且仍占一项。模板使用图片列表的“项数”校验完整输出；少项或多项均报错，整页成功后才保存。零检出页不发送 API。模板不调用 OCR 或本地机翻，也不在章末提取译名；已有译名字典仍参与提示词。可下载[可导入的模板文件](templates/vl-page.lmworkflow.json)。

## 6. API 与图片

Chat、Responses、Gemini 均支持角色消息和真实图片附件。上下文可包含多组用户／助手 few-shot。普通变量在追加对话时保存，避免循环项离开作用域后失效；直接引用的译名字典在实际请求时取最新内容。

文本输出接收文本；其他可序列化类型要求完整 JSON，校验类型、必需字段、额外字段。允许完整 Markdown JSON 围栏；非法、截断、部分 JSON 不写回。默认视觉气泡输出为：

```json
{"source":"当前气泡的完整原文","translation":"对应译文"}
```

每个气泡循环分支独立持有当前气泡、局部变量和裁图；分支内的步骤顺序执行，所有分支完成后才继续循环外的行。默认 VL 模板每次只发送当前气泡裁图，返回单个 `source / translation` 记录，不需要模型回传 `bubbleId`，直接写回当前气泡。气泡内多行／多块文字合并在两个字段中，无文字时两个字段均为空字符串。单条记录返回 JSON 列表会失败并明确报告列表项数；提示词须与输出类型保持一致。批量／整页回填仍使用气泡 ID 完整对应校验。已有保存的工作流及队列快照保留原程序，需自行同步调整提示词和输出类型。

循环变量即使复制或改名也保留当前项身份。API 与流式 API 未选择附件时，自动使用最近一层 `<气泡>` 循环项的裁图；明确选择“不附图”或空图片列表时关闭自动附图。循环外不自动附图。运行时为真实附件补充读取图片的提示，单区域 `source / translation` 输出明确约定无可辨认文字时返回两个空字符串，因此旧视觉工作流也能处理无文字候选图。

Chat 协议的记录／列表输出自动按所选类型发送 JSON Schema，约束字段及转义；用户自定义参数中的 `response_format` 优先生效。服务端明确以 HTTP 400／422 拒绝结构化参数、且尚未返回正文时，重试一次普通请求；两次实际 HTTP 请求都记入日志。其他协议继续使用提示词和本地结构校验。模型的说明文字、错误信息或示例 JSON 不会被截取成真实译文。

同一 `协议+主机+端口` 的配置共享服务器预算，使用已配置的最低并发上限，并遵守各配置上限。用户电脑测试服务设为 **2**，气泡翻译与章末提取共用两个许可。服务器别名不会自动合并，配置应使用同一地址。

单请求附件张数不限，合计 16 MB Base64，超出请分批。区域裁图在内存中编码为 PNG，整页图片编码为 JPEG。网络失败按 API 配置有限重试；收到部分内容后失败不重发。工作流额外重试只针对本地 SEG／OCR／机翻，避免叠加 API 重试。

入队冻结 API 地址、模型、协议、参数及并发；Key 不进入任务快照，运行时从加密存储按配置 ID 读取。删除引用的 API 配置会明确报错。

含本地机翻的语言选择仍由已下载完整路线生成，支持英语中转，无手工输入。只使用 API 的工作流从系统语言列表选择漫画源／目标语言，无需下载机翻包；实际语言能力由所选 API 模型决定。

## 7. 实时漫画译名字典与提取

**没有章节字典，也没有自动章节词典快照。** 第 39 章先收录的译名，第 7 章下一次读取就能使用，不需要改变章节同步／异步模式。

新增按 `(mangaId, source)` 去重，数据库 `INSERT IGNORE` 原子保留现有值。无论人工、自动、章节顺序，后来新增不能覆盖已有原词；一次输出内同名重复也保留第一项。用户明确编辑选中的条目是独立操作，改名不能覆盖其他已有条目。

视觉模板从气泡图片取得原文与译文，章末使用成对记录提取名字，不从只有译文的段落反推原文。可编辑 few-shot：

```text
用户：输入 [{source:"Akira arrived at Moon Academy.",
            translation:"阿基拉抵达月亮学院。"}]，已有字典 {}。
      只提取有证据且原文／译文一一对应的人物、地名、组织名。
助手：[{source:"Akira",translation:"阿基拉"},
      {source:"Moon Academy",translation:"月亮学院"}]
```

实际请求加入实时字典及本章对照，返回 `[{source,translation}]`，没有新增返回 `[]`，再新增译名。提示词、示例、提取范围、API、位置均可编辑。专名识别属于模型行为，漫画译名管理可检查、编辑和删除。

本地流程可显式插入字典匹配替换：保留气泡原文，新建机翻输入文本，匹配后的内容写入该文本，再交给机翻。内置默认机翻不自动改写原文。

## 8. 持久化、失败与边界

`core:workflow` 保存并执行类型树：稳定行／变量 ID、类型、引用、模板绑定、输出、模式、子行、否则分支。最大 500 行、16 层、单程序 1 MB。工作流存储 schema 2，旧表单副本自动补本地机翻结构；任务 schema 2 保存完整程序，已有 schema 1 任务仍走兼容执行器。

气泡分支全部完成才保存页 JSON。页失败保留旧 JSON 与其他完成页，错误包含失败行名称。章末提取失败保留完成页，重试复用这些页。进程结束后，重启将运行中任务标为 INTERRUPTED；已保存页面保留，由用户手动重试。

阅读器单页翻译执行所选程序，章节／页面范围收窄为当前页，该次章末处理也只看到当前页。清除使本页未翻译并排除当前任务；主动重译或新入队可再次处理。

翻译/导出已接入前台服务与通知；任意工作流断点、任意脚本、页级中间值恢复和旧译文历史尚未提供。自定义变量属于本次运行；缓存页提供自动对照记录，不恢复上次临时变量。旧保存工作流中的预处理与末尾返回行自动转换为普通每项及收集参数；旧队列快照按原程序兼容执行。

## 9. 流式结构化列表与即时回填

“API 请求－流式输出”是嵌套作用域。输出变量必须是结构化记录／字典列表，循环变量类型等于列表条目类型。收到完整对象及其逗号／列表结束符后执行内层行，内部步骤依次执行；不支持文本片段或半个对象，兼容完整 JSON 代码围栏。例：

```text
新建 收到的译文<列表<气泡对照>>
每 当前条目<气泡对照> 在 API请求－流式输出（提示词模板，输出：收到的译文） {
    按气泡 ID 回填（当前条目）
    # 或按气泡顺序回填（当前条目，当前条目序号）
}
# 请求结束、完整校验通过后才执行后续行
```

输出列表逐项累积，内部对当前条目字段的修改会写回列表；当前条目序号从 1 开始。ID 回填检查本页归属和已有 OCR 原文；有期望气泡列表时，条目先校验 ID／原文／页身份，再执行内层步骤，结束时校验完整覆盖。顺序回填适合按 SEG 原顺序返回的模型，越界会失败；带 OCR 原文时仍禁止改写原文。模型顺序不可靠时应使用 ID。

回填立即发布内存阅读预览，不生成 PNG，也不提前保存页 JSON 或增加已完成页计数。预览保留完整气泡几何，未取得译文的气泡显示原图；仅原文／译文变化不会重新读取原图准备遮罩，只更新字形布局。请求结束并且整页成功后才原子保存 JSON；失败／中止则清除临时预览。内层其他步骤（例如译名新增）已完成的效果保留；收到任何内容后的网络错误不重发。排序、暂停仍遵守当前页边界；整漫画请求保持已接受的等待规则。

## 10. 导入、导出与固定标识

工作流列表右上角导入，每张卡片右上角导出，均使用系统文件选择器。文件格式 `lmreader.workflow`、版本 `1`，包含名称、说明、并行上限、重试和完整类型树；不包含 API Key／完整 API 配置。导入生成新的工作流 ID。

```json
{"format":"lmreader.workflow","version":1,"editable":false,"name":"固定示例","description":"","parallelLimit":8,"retries":1,"program":{"version":1,"rows":[]}}
```

以上只演示文件头，实际 program 应保留导出文件中的完整程序。默认导出的 editable 保持原值，应用没有修改标识的选项，也不能在导出时选择。用 VS Code 等外部工具将 editable 改成 false 制作固定模板。导入后固定工作流只读，复制仍保留固定标识；**允许“为所有请求选择 API”统一替换绑定**。导入时可逐个文件配置引用绑定本机 API，也可暂不绑定；缺绑定的草稿不能入队。已有任务使用旧快照。

## 11. API 日志

主菜单 → API 日志。按漫画分组；配置测试单独分组。每个实际 HTTP 请求及每次重试各有记录，显示时间、章节／页／步骤、配置／模型、请求方式／地址、协议、HTTP 状态、耗时、请求、正文、思考和错误。阅读器发起的单页重译同样记录，步骤以“单页重译”标记。未完成请求在应用重启后显示中断。日志为应用私有文件，不随备份迁移。

图片记录 MIME 和估算大小，不保存 Base64；授权头／API Key 不写入日志，地址移除用户信息和查询参数。日志最多 500 条／64 MB，删除最旧已结束记录；请求文本至多 100 万字符、正文 400 万、思考 100 万。请求中记录暂不清理。日志故障不阻断真实请求。HTTP 200 后的 JSON／结构／ID 校验失败也会将对应请求标记失败，保留 HTTP 状态及模型原始正文，错误说明本次实际附件数。
