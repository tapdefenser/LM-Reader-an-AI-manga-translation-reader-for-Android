# LM-Reader 使用说明

[English](USAGE.en.md) · [项目首页](../README.md)

本文包含 `v0.1.6` 的使用说明，屏幕翻译已随本版正式提供。正式安装需要已签名 APK；未签名候选不能直接安装。目标为 Android 8.0+、arm64-v8a / x86_64 设备。

## 图库、阅读与语言

首次启动进入图库路径设置。选择目录，按实际结构选择单/多章节布局，再扫描。图片目录、ZIP、CBZ、PDF 使用统一入口。路径被移动或撤销授权后，到路径设置重新选择原目录。漫画详情支持加入书架、分类、阅读与章节操作；阅读器可切换分页/条漫、缩放、裁白边和预加载。

漫画身份按文档路径区分，名称只用于显示。不同路径的同名漫画会各自显示；同一路径重复扫描更新原记录，保留收藏、阅读进度和译名字典。扫描结束时核对已加载的分页范围，修复扫描期间插入记录导致的漏项，继续保持按批加载。

在漫画详情页点击右上角「⋮ → 译名管理」，可管理这部漫画的译名字典。

「设置 → 通用 → 应用语言」提供跟随系统、简体中文、English。跟随系统只检查首选语言：简中系统显示中文，其他系统（含繁中）显示英语。系统首选英语、第二语言简中时仍显示英语。手动选择优先，切换后界面重建；漫画标题、路径、用户输入和漫画翻译目标不受影响。

## 翻译、工作流与编辑

先填写漫画的原文/目标语言与工作流。本地链路使用 Seg、OCR 和专用机翻；选择「本地机翻」使用 Bergamot CPU 引擎。语言包按方向安装，优先直达，其次寻找已安装包构成的最短路径，不限定英语中转，最多三段，每一段均需安装。API 链路在「设置 → API 与翻译引擎」添加 URL、模型、密钥和协议，再测试连接。API 标识绑定本机配置，导入别人工作流后要重新确认绑定。

详情页三点菜单底部是「翻译选项」，「译名管理」位于倒数第三项。含 API 的工作流可在翻译选项选择「API（适用于本漫画）」：跟随工作流默认，或用一个配置覆盖本漫画的所有 API 步骤。语言列表将已下载完整路线（含中转）的语言置顶，不自动选择语言。本地机翻选项提供离线翻译包下载入口。获取语言包列表只下载元数据，刷新为手动操作；语言包按需下载。模型页仅管理和测试语言包，任务使用本地 Bergamot 引擎。

漫画介绍支持长按选择和复制文字；长介绍可先点「显示更多」展开，再选择全文。介绍内容保持原文。

猫爪工作流可从三种参考模板开始，调整循环、变量、并发和提示词，详见[工作流说明](WORKFLOWS.zh-CN.md)。外部 API 工作流可能发送页面图像、识别文字、上下文和提示词给所选提供方。

漫画详情可将全部或所选章节加入翻译队列，支持排序、暂停、取消、重试与步骤监视。阅读器可重译本页、清除译文或编辑气泡，支持撤销、保存和离开前提示。译文/气泡保存为私有 JSON，叠加在原图上；原始漫画不会被翻译或编辑改写。清除译文前按需备份。

气泡编辑模式可新建气泡，包括尚未翻译的页面。选中气泡后拖动主体移动、拖动右下把手缩放、拖动右上把手旋转，A+／A− 调整这个气泡的字号。一次拖动作为一次撤销操作；保存后的几何、旋转、字号同时用于阅读与导出。

游离文字译文使用整个检测框自动换行和适配字号，减少内边距；原文遮罩仍按检测轮廓填充，译文增加对比描边，阅读器与导出使用相同排版。已有译文可直接重新绘制，无需重新调用 API。

新默认值为 SEG 判定阈值 35%、文字检测置信度 35%、游离文字行间合并距离 45%、遮盖不透明度 85%、文字边距 7%。行间合并距离 100% 表示允许一行字高的间隔，竖排按列宽计算，范围为 0–200%。设置按漫画保存，修改检测参数后需重新识别／重译才能更新检测框；已保存的设置与已入队任务保持原值。

## 关于与检查更新

「设置 → 关于」显示已安装版本，提供 GitHub 项目主页和检查更新。自动检查频率可选「每次启动时」「每日首次启动时」「每三日」「关闭」，默认每日首次启动时。启动检查和手动「检查更新」发现新版本后，都会直接弹出相同的更新日志弹窗。

在更新弹窗中点击「下载更新安装包」可后台下载适合设备的 APK；关闭弹窗或重新打开应用后，下载仍可继续，可在关于页查看进度。下载完成后校验大小、公开 SHA-256（如提供）、包名、版本和发布证书，再提供「安装更新」。安装通过 Android 安装程序完成，首次使用可能需要允许本应用安装更新包。关闭自动检查仍可手动检查；网络失败与 GitHub 访问受限分别提示重试。

## 后台与通知

翻译队列中的单页在重试次数用尽后跳过，继续本章其余页和后续章节。已完成的译文保留；全部可处理页结束后，含失败页的章节保留错误与重试入口，不会因一页失败提前停止整章。整漫画 API 也会略过预处理失败的页，释放失败页的缓存额度，避免挡住后续页。

章节翻译和导出使用前台服务，切页面、切后台和锁屏不会主动取消队列。通知分为翻译与导出两个进度卡片，显示漫画、章节、已完成／总页数和未完成章节数，翻译还显示 SEG／OCR／API 当前并发数。每张卡片可单独暂停或继续，点击打开对应队列；暂停及完成／失败结果在服务停止后继续保留，结果通知可划掉。翻译暂停会等待当前页收尾，整漫画 API 请求保留已有等待规则；继续只恢复暂停项，失败章节需在队列中明确重试。

翻译队列三点菜单可勾选「资源利用优先」（默认）或「队列顺序优先」。前者让不同 API 与本地机翻并行，等待任意 API 步骤时检查后续漫画；没有可接入的漫画时可提前 SEG 本漫画的后续页面。同一 API／服务器共享额度。后者按队列顺序优先完成漫画。章节简介与队列同步显示翻译页数和失败状态；书架／图库底部显示翻译信息栏，点击打开队列。

Android 13 及以上首次开始任务时请求一次通知权限，拒绝不会停止任务，也不会反复弹窗。「设置 → 后台任务与通知」可重新申请权限或打开系统通知设置；单独关闭任务通知类别时，入口打开对应类别设置。通知权限未允许时，通知栏不显示进度。

暂停翻译停止后续调度并保留当前页完成结果，整漫画 API 响应可能需等待处理结束。导出暂停停止继续写入并保留快照。取消不会删除已有译文。服务停止/系统后台时限会暂停任务；进程终止后运行中任务标为中断，已保存结果保留，需打开应用手动重试。任意工作流中间变量不提供断点恢复，厂商省电策略仍可能影响执行。

## 屏幕翻译（当前开发版）

以下说明描述当前开发版的实现与设置，尚未作为正式更新发布。

书架、图库的翻译图标可拖动，点击打开「启动／停止屏幕翻译」和「屏幕翻译设置」。启动时按所选工作流预热实际需要的资源：默认「仅游离文字」检测气泡内外的全部文字，以文字框绘制，只加载文字检测 DET；工作流有 OCR 才加载对应识别语言，有本地机翻才加载对应模型路线。需要气泡轮廓的范围才加载气泡 SEG。图库漫画工作流沿用相同的按需加载规则。

应用外悬浮球在加载、翻译期间变暗，仍可拖动；加载期间不接纳截图，待引擎就绪后再点一次。球首次到达边缘仍完整可见，再次向外拖动才收起；点击收起的球只展开。在 LM-Reader 内隐藏系统球与遮罩。常驻通知显示资源及「启动／停止翻译引擎」「屏幕翻译设置」。关闭连续翻译清除遮罩与区域记录，但保留引擎；通知中的停止引擎释放屏幕任务的资源保留，队列正在使用的共享机翻模型不会被强制卸载。停止屏幕翻译移除系统球。 引擎已启动时，修改屏幕翻译设置、切换工作流或保存所选工作流的编辑会自动生效；保留仍需要的模型，仅增减所需资源，后端变化只重建对应的 SEG 或 OCR。旧屏幕任务取消，原本开启的连续翻译自动恢复。主动停止引擎后，编辑设置不会自行重启引擎。

- **手动截图**：点球翻译当前画面，处理中不重复提交。译文绘制、按钮恢复之后建立检测基线，后续使用同一种画面来源，避免把自己的译文当作页面变化。检测到移动后默认延迟 120 ms 清除，不自动翻译下一页。
- **浏览**：原「漫画」模式。拖动、缩放期间持续计算光流并移动已有译文，不等待手指松开；新增识别默认等待画面稳定 180 ms，新区域宽、高至少 16 截图像素才提交。普通 SEG/DET 实际只接收新增裁块，按这一张干净截图的光流后位置切除已有原文区域，包括尚在翻译的区域。新检测文字接触旧文字，或距离不超过「新旧文字区域合并间距」（默认 8 截图像素）时，才恢复同帧原图中的完整合并裁块并再次 SEG/DET，最终区域确定后再提交 OCR。距离根据文字区域判断，不根据空白条带的外接框扩大合并；设为 0 时仅合并接触或重叠。重 SEG 后形状和原图纹理均未变化的旧文字复用现有对象，不重复 OCR/翻译。最终区域先绘制空遮罩并立即跟踪；它接管背景后，旧区域记为已过时并关联新 SEG 参数，只取消被替代区域的工作，旧译文仍保留。译文逐泡回填同一对象，不退回截图时的位置；旧区域被拆成几个新区域时，已填部分先显示，旧文字在对应部分被新文字覆盖后才消失。空结果、识别失败不会先删除旧译文。会话数据库记录待填、已填和已过时区域及替代关系，光流跟随不逐帧写库。气泡完全离开按屏幕宽、高分别外扩的区域才删除，默认 25%。关球再开清除覆盖记录与会话，可重译整屏。
- **视频**：默认全屏，也可调整上下边界。比较新画面的灰度差异，不等待稳定，背景动画也可能触发。新气泡回填后逐个显示，其他旧译文保留到这块区域的新结果完整到达，再清理残留；完整空结果也会清除旧字幕。旧任务不能覆盖或清除较新结果。再点球停止并清除。

三种模式都按已回填的气泡逐个更新画面，不等整页全部翻译完成；工作流本身若在收齐 API 输出后才执行回填，则仍按该回填步骤的时间显示。只有浏览模式会提前绘制空遮罩，手动和视频不绘制等待文字的空遮罩。

浏览中的弹窗或菜单会暂时遮住底层译文相应区域，底层气泡和覆盖记录仍保留，窗口 ID 改变不再直接当作换页。系统暂时不提供底层窗口时暂停采样，弹窗关闭后接回原场景；仍能取得底图时只排除遮挡区域。应用内绘制的局部菜单用网格纹理连续性识别，周围仍保留原图时不按匹配超时清空整页。弹窗期间暂停新增识别，已回填的译文继续保留。

新区块的矩形差集是像素所有权掩码，不逐个切成独立 SEG 图片。相邻碎块先归并，按默认 64 截图像素保留边界上下文，已有原文仍从输入中切除；细长的 L 形新增区域保持为局部裁块，避免扩大为整屏。最小新增尺寸在归并后判断。跨裁块的新文字也会恢复同帧完整原图再 SEG，OCR 只使用最终文字区域和文字行，丢弃被替代的半截文字行。上下文始终限制在选定翻译区内。

已识别分块还会按检测间隔用现有跟踪小图做 4×4 均匀纹理校验，不额外截图。在稳定、可靠且无弹窗的两张不同有效帧中，至少四个位置可比较、覆盖至少 70% 可见取样位置，且其中至少 70% 明确失配，才释放该块的覆盖记录以重新识别。空 SEG 块也参与校验，避免记录长期阻止新内容进入。气泡独立判断：仍匹配的保留，明确失配的删除；整体变暗、遮挡、可见纹理不足不会直接清空整页。

浏览、视频各有「屏幕区域选定」，入口在三个模式选项下面，两种模式独立保存当前翻译区。方案库可共享，一个方案同时保存竖屏、横屏各最多 8 个矩形；加载方案会复制到当前模式，修改库中方案不会自动改变另一模式已选的区域。区域弹窗支持滚动并显示可拖动滚动条，横屏也能访问全部内容。左下角「新建」输入一个未使用的名称，创建横竖屏均为全屏的空方案；下方「删除当前方案」只删除库里的方案，已应用的翻译区保留。选择编辑方向后隐藏设置，显示目标应用和半透明工具箱，触摸仅用于添加、移动、调整边角或叉号删除矩形；完成后回到设置，点「应用区域」保存当前命名方案并应用到本模式。编辑器不再提供保存按钮，取消区域弹窗不应用草稿，但已经执行的新建／删除操作保留。某个方向没有矩形时该方向识别全屏。编辑器请求真实横竖屏，退出后解除自身方向请求；系统未执行时会提示旋转设备，不把竖屏画面伪装成横屏。跟踪、变化检测、识别和遮罩绘制均限制在选区并集内，选区间空隙不计入已识别区域。旧原文半出屏或超出选区时保留完整旧译文，等它可完整重识别后再替换。

浏览、视频必须开启无障碍辅助。启动时自动打开辅助设置，返回时未开启不会循环跳转。Android 14 及以上优先请求单应用录屏，请在系统授权框选择要翻译的应用。验证为干净的应用流后，持续接收本地原始帧；跟踪只取灰度小图，识别只在处理槽开放时取出图片，不编码视频、不传输网络。取消录屏授权，或设备无法提供已验证的应用流时，改用干净窗口截图，统一遵守系统截图限频；该路径的跟随速度受至少 334 ms 的请求间隔限制。两种连续来源都保持遮罩可见，不执行隐藏／截图／恢复循环。选择整屏录制而包含自家悬浮球的来源不会用于连续翻译。

Android 13 及以下没有可移植的干净连续采集接口，本版保留手动模式。手动模式可优先使用 Android 14 以上的窗口截图；普通录屏兼容路径仅首次识别时按显示帧边界隐藏、截图并恢复，后续监测保持译文可见。停止录屏会结束手动截图会话；连续模式在无障碍窗口截图可用时自动切换来源，保留气泡和已加载资源。暂时没有新帧、窗口切换或截图限频会等待重试。关闭辅助或锁屏会停止会话。

浏览跟踪与翻译独立，各自完成当前工作再请求下一帧；任务超过目标帧周期时继续完成，不按定时器丢弃。跟踪采用约 192 像素宽灰度图、8×8 网格均匀角点、稀疏光流和三参数 RANSAC，分别拟合正文运动与固定界面，避免固定搜索栏压制缩放估计。默认「整屏＋逐气泡」也校验游离文字框：按候选尺度比较原图模板，选择跟随正文或保持屏幕位置；两张不同有效帧均明确失配才删除，可见纹理不足时保留。两个档位均逐对象校验；「整屏」按全局变换校验，「整屏＋逐气泡」还尝试恢复固定位置。移出屏幕的块只比较屏幕内可见原图，已知弹窗遮挡不计为失配；明确失配删除后会取消该区域任务并阻止迟到译文重新出现。弱匹配时重新定位，无法解释的新页面清除旧记录；较早结果不能覆盖已发布的合并区域。缩放平滑基于累计变换，细小缩放不会被每帧死区吞掉。目标帧率可选 15／30／60，实际速度受设备、画面和来源限制。GPU 加速图像降采样与灰度化，启动时检查硬件缓冲区结果、方向与总耗时，不能加速或失败时自动使用 CPU。大面积纯色、重复纹理仍可能无法可靠跟踪；不跟随旋转或透视。

整体半透明纯色蒙版的亮度和对比度变化会在小图跟踪中补偿：排除无效区域后拉伸对比度，光流局部补偿增益／偏移，运动确认与逐气泡校验使用去均值、归一化对比度的纹理相似度。蒙版出现、消失时仍可跟随同时平移和缩放；OCR 原图保持原样。接近不透明、模糊或遮挡导致纹理消失时仍不能保证跟踪，不把纯色噪声当作运动。

连续模式始终启用下一画面预处理，不再提供开关；最多两张已接纳画面。间隔从实际提交开始计时，下一张必须同时满足前一张整张 SEG/DET、OCR 就绪、提交间隔已到、处理槽和缓存可用。两槽占满时等待任务完成，不继续取完整识别截图。无变化的检测也遵守间隔。

例如间隔 200 ms、翻译耗时 500 ms：第一张提交后，SEG/OCR 若在 120 ms 就绪，等到 200 ms 才取第二张；若在 250 ms 才就绪，就在就绪后取第二张。两张占满以后，第一张完成释放槽再检查时间，已经过间隔则立即取最新画面。未接纳的中间流帧跳过，已接纳的结果完整保留。自定义工作流中依赖 API 返回值或条件的 OCR 保持原执行顺序，无法安全提前识别时保守地等本张完成。

屏幕翻译独立保存工作流、API 覆盖、语言、检测、排版、SEG／OCR 并行与缓存设置；API 和机翻额度、优先级与漫画队列共享。暂停队列可以减少屏幕等待。已接纳画面的完整结果可超过预算，随后阻止下一张进入，不截断气泡；未发布结果受保护，失败、取消的输入和预处理结果保留供重试。没有任务能继续释放缓存时给出阻塞提示。重试画面与当前屏幕不同则不绘制旧译文，需重新截图。

单页失败隔离同样适用于三种屏幕模式：工作流重试用尽后，记录当前画面错误、保留输入和预处理缓存，释放处理槽位与资源额度，继续其他裁块及后续画面。手动模式恢复可点击状态；浏览和视频保持连续运行，已有译文保留，仅撤回失败的空遮罩。失败的浏览区域按截图当时的内容坐标记为已尝试，静止时不自动反复提交；新区域露出或原图内容明确失配后可继续识别，也可点重试入口处理保留的画面。主动停止、截图权限失效和无法释放的缓存阻塞仍按各自规则处理。

手动与连续任务直接复用本次截图及一次计算的哈希，避免每个文字区域重新读取、解码原图；可安全提前的 OCR 与已有区域的机翻重叠。设置显示本次总耗时和截图、图像准备、SEG/DET、OCR、机翻、排队、绘制耗时；并行阶段显示累计时间，不能直接相加。速度需按自己的设备、页面文字数量和模型测量。

备份包含屏幕与机翻设置，不包含失败截图和模型。旧「漫画」设置迁移为「浏览」，废弃跟随档位、预处理开关忽略；用户已保存的范围与视频区域继续保留，新设置默认仅游离文字和全屏视频。

## 导出与失败恢复

在导出设置分别选择单/多章节目标目录，再选 PNG、JPEG 或 CBZ；从漫画详情选择章节入队。已译页合成气泡，未译页按所选格式输出。PDF/ZIP 可作为输入，但当前没有 PDF/ZIP/WebP 输出。名称冲突自动编号，输出完成并重新读取校验后才重命名。

暂停、失败和中断保留原图/译文快照及完整页面；后来的原图/译文修改不改变重试使用的快照。授权丢失时重新选择目录；有旧目录待清理文件时需恢复旧目录授权。清理失败保留记录和原因。「暂停导出并清理临时文件」保留未完成任务的可继续快照。

快照占用私有存储；单页上限 64 MB，章节原图和输出各有 2 GB 上限。空间不足时释放空间后重试，不要直接删除正在使用的私有文件。

## 备份、迁移与恢复

备份包含设置、图库索引、书架分类、进度、字典、译文/人工编辑、工作流及无密钥 API 配置；不包含原始漫画、模型、请求日志、导出产物或导出队列。目录权限不可迁移。恢复后重新授权目录、填写密钥、安装模型，再手动继续任务。当前支持 schema 11。

恢复先校验完整包，停止写入者并保留本机回滚副本。失败会回滚，进程中断后下次启动优先恢复日志。若提示恢复未完成，保留应用数据并重新打开，避免卸载或清空数据。详见[备份与任务恢复](BACKUP.zh-CN.md)。

Debug (`com.lmreader.debug`) 与 Release (`com.lmreader`) 可并存。迁移测试数据时从 Debug 导出备份，再在正式签名版恢复；它们不是同一包的覆盖升级。

## 反馈

提供应用版本、设备/Android 版本、界面语言、输入格式、工作流和复现步骤，说明发生在阅读、翻译、导出还是恢复。仅附脱敏日志和有权分享的小样本；不要上传密钥、完整私人漫画或未经检查的备份。

## 完成任务

已完成的翻译与导出任务会自动出队，译文、章节完成状态和已导出文件继续保留。失败、中断与暂停任务保留，方便重试或继续。
