# LM-Reader 使用说明

[English](USAGE.en.md) · [项目首页](../README.md)

本文对应 `v0.1.4`。正式安装需要已签名 APK；未签名候选不能直接安装。目标为 Android 8.0+、arm64-v8a / x86_64 设备。

## 图库、阅读与语言

首次启动进入图库路径设置。选择目录，按实际结构选择单/多章节布局，再扫描。图片目录、ZIP、CBZ、PDF 使用统一入口。路径被移动或撤销授权后，到路径设置重新选择原目录。漫画详情支持加入书架、分类、阅读与章节操作；阅读器可切换分页/条漫、缩放、裁白边和预加载。

漫画身份按文档路径区分，名称只用于显示。不同路径的同名漫画会各自显示；同一路径重复扫描更新原记录，保留收藏、阅读进度和译名字典。扫描结束时核对已加载的分页范围，修复扫描期间插入记录导致的漏项，继续保持按批加载。

在漫画详情页点击右上角「⋮ → 译名管理」，可管理这部漫画的译名字典。

「设置 → 通用 → 应用语言」提供跟随系统、简体中文、English。跟随系统只检查首选语言：简中系统显示中文，其他系统（含繁中）显示英语。系统首选英语、第二语言简中时仍显示英语。手动选择优先，切换后界面重建；漫画标题、路径、用户输入和漫画翻译目标不受影响。

## 翻译、工作流与编辑

先填写漫画的原文/目标语言与工作流。本地链路使用 Seg、OCR 和专用机翻；语言包按方向安装，经英语中转时需安装全部所需方向。API 链路在「设置 → API 与翻译引擎」添加 URL、模型、密钥和协议，再测试连接。API 标识绑定本机配置，导入别人工作流后要重新确认绑定。

猫爪工作流可从三种参考模板开始，调整循环、变量、并发和提示词，详见[工作流说明](WORKFLOWS.zh-CN.md)。外部 API 工作流可能发送页面图像、识别文字、上下文和提示词给所选提供方。

漫画详情可将全部或所选章节加入翻译队列，支持排序、暂停、取消、重试与步骤监视。阅读器可重译本页、清除译文或编辑气泡，支持撤销、保存和离开前提示。译文/气泡保存为私有 JSON，叠加在原图上；原始漫画不会被翻译或编辑改写。清除译文前按需备份。

游离文字译文使用整个检测框自动换行和适配字号，减少内边距；原文遮罩仍按检测轮廓填充，译文增加对比描边，阅读器与导出使用相同排版。已有译文可直接重新绘制，无需重新调用 API。

翻译选项中的「游离文字行间合并距离」默认 0，逐行独立处理；调大可合并相邻行。100 表示允许一行字高的间隔，竖排按列宽计算，范围为 0–200。设置按漫画保存，修改后需重新识别／重译才能更新检测框。新建遮罩设置的不透明度默认 60%，已保存的设置与已入队任务保持原值。

## 关于与检查更新

「设置 → 关于」显示已安装版本，提供 GitHub 项目主页和检查更新。自动检查频率可选「每次启动时」「每日首次启动时」「每三日」「关闭」，默认每日首次启动时。启动检查和手动「检查更新」发现新版本后，都会直接弹出相同的更新日志弹窗。

在更新弹窗中点击「下载更新安装包」可后台下载适合设备的 APK；关闭弹窗或重新打开应用后，下载仍可继续，可在关于页查看进度。下载完成后校验大小、公开 SHA-256（如提供）、包名、版本和发布证书，再提供「安装更新」。安装通过 Android 安装程序完成，首次使用可能需要允许本应用安装更新包。关闭自动检查仍可手动检查；网络失败与 GitHub 访问受限分别提示重试。

## 后台与通知

章节翻译和导出使用前台服务，切页面、切后台和锁屏不会主动取消队列。通知分为翻译与导出两个进度卡片，显示漫画、章节、已完成／总页数和未完成章节数，翻译还显示 SEG／OCR／API 当前并发数。每张卡片可单独暂停或继续，点击打开对应队列；暂停及完成／失败结果在服务停止后继续保留，结果通知可划掉。翻译暂停会等待当前页收尾，整漫画 API 请求保留已有等待规则；继续只恢复暂停项，失败章节需在队列中明确重试。

Android 13 及以上首次开始任务时请求一次通知权限，拒绝不会停止任务，也不会反复弹窗。「设置 → 后台任务与通知」可重新申请权限或打开系统通知设置；单独关闭任务通知类别时，入口打开对应类别设置。通知权限未允许时，通知栏不显示进度。

暂停翻译停止后续调度并保留当前页完成结果，整漫画 API 响应可能需等待处理结束。导出暂停停止继续写入并保留快照。取消不会删除已有译文。服务停止/系统后台时限会暂停任务；进程终止后运行中任务标为中断，已保存结果保留，需打开应用手动重试。任意工作流中间变量不提供断点恢复，厂商省电策略仍可能影响执行。

## 导出与失败恢复

在导出设置分别选择单/多章节目标目录，再选 PNG、JPEG 或 CBZ；从漫画详情选择章节入队。已译页合成气泡，未译页按所选格式输出。PDF/ZIP 可作为输入，但当前没有 PDF/ZIP/WebP 输出。名称冲突自动编号，输出完成并重新读取校验后才重命名。

暂停、失败和中断保留原图/译文快照及完整页面；后来的原图/译文修改不改变重试使用的快照。授权丢失时重新选择目录；有旧目录待清理文件时需恢复旧目录授权。清理失败保留记录和原因。「暂停导出并清理临时文件」保留未完成任务的可继续快照。

快照占用私有存储；单页上限 64 MB，章节原图和输出各有 2 GB 上限。空间不足时释放空间后重试，不要直接删除正在使用的私有文件。

## 备份、迁移与恢复

备份包含设置、图库索引、书架分类、进度、字典、译文/人工编辑、工作流及无密钥 API 配置；不包含原始漫画、模型、请求日志、导出产物或导出队列。目录权限不可迁移。恢复后重新授权目录、填写密钥、安装模型，再手动继续任务。当前支持 schema 11。

恢复先校验完整包，停止写入者并保留本机回滚副本。失败会回滚，进程中断后下次启动优先恢复日志。若提示恢复未完成，保留应用数据并重新打开，避免卸载或清空数据。详见[备份与任务恢复](BACKUP.zh-CN.md)。

Debug (`com.lmreader.debug`) 与 Release (`com.lmreader`) 可并存。迁移测试数据时从 Debug 导出备份，再在正式签名版恢复；它们不是同一包的覆盖升级。

## 反馈

提供应用版本、设备/Android 版本、界面语言、输入格式、工作流和复现步骤，说明发生在阅读、翻译、导出还是恢复。仅附脱敏日志和有权分享的小样本；不要上传密钥、完整私人漫画或未经检查的备份。

## 完成任务

已完成的翻译与导出任务会自动出队，译文、章节完成状态和已导出文件继续保留。失败、中断与暂停任务保留，方便重试或继续。
