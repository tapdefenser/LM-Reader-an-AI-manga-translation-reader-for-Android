# 手机 Release 自测（2026-10-21）

本轮为保留数据的 Release 覆盖升级，沿用 `com.lmreader` 和原发布证书。版本号仍是 `0.1.11 / 13`；具体构建以本轮 APK 摘要为准。安装与校验结果记在[实施记录](2026-10-21-redesign-implementation.zh-CN.md)。ARM 语音质量、耗时和后台表现由本轮实测确认。

## 先做这五项

1. **确认旧数据。** 打开应用，确认原书架、分类、工作流和已下载翻译模型可读取。
2. **图库与播放。** 进入图库，在下方切到“视频”，按系统提示授权。点视频行应直接播放。切到书架后仍为视频模式；退出重开也应保持。分别测试文件夹、名称/自然数/大小/时长排序，观察各页面的滚动位置是否保留。
3. **确认本地 ASR。** 进入“设置 → API 与翻译引擎 → 本地 ASR 模型”，将已下载的 Whisper Base 设为当前；只有一个已安装模型时会自动采用。无需重复下载或在视频选项中再次选择。模型未随 APK 附带，其他模型也在此处管理。
4. **短视频仅字幕。** 找一个约 30–60 秒、语音清楚的视频。视频三个点 →“翻译选项”→“仅字幕”；从列表选择源/目标语言和字幕翻译工作流，再点“加入队列”。识别自动采用本地 ASR 设置中的当前模型，视频中无需重复选择。翻译工作流有 API 节点时才显示字幕 API 列表；本地机翻需对应语言包。ASR 原文和后续译文分别检查。
5. **退出播放器。** 入队后返回图库或桌面，过一会再看“翻译队列”。任务应保留身份、阶段和进度；缺模型/授权或系统限制时，应说明等待原因。返回视频检查字幕文字、时间与声音是否对应。记录实际耗时，不预设完成时间。

## 本轮队列与视频修复优先回归

1. 加入两部漫画的章节和一个视频。页面应名为“翻译队列”，漫画大卡片下显示各章卡片，视频参与共同排序。完成或取消后卡片自动出队，已有成果保留。
2. 右上角三个点应有全部开始、全部暂停、全部取消、已加载资源，以及自然数、修改时间、首字母。点每种排序后都有升序/降序；修改时间使用漫画队列章节的最近文件修改时间、视频原文件修改时间，未知值最后。
3. 分别用大卡片和章节卡片右上角三个点测试上移、下移、开始/暂停、取消。漫画与视频的大卡片共用一个顺序；章节在所属漫画内移动。
4. 点“全部暂停”，等卡片达到安全边界后只开始其中一张：其余保持各自暂停。再新加一个任务，应正常排队，不继承暂停。点“全部开始”应从上到下恢复所有暂停/中断卡片，失败项仍需单独“重试失败”。这些操作没有额外的全局暂停开关。
5. 视频翻译选项中，分支工作流含 API 节点时，其上方显示“画面 API”或“字幕 API”，点击打开列表。分别选择后，该分支的所有 API 节点使用所选配置；纯本地工作流不显示 API 行。
6. 重试此前因 `Starting FGS with type none` 等待的视频，或更新选项重新排队。选择“画面与字幕”后退出播放器，检查两支进度和等待原因；缺识别模型时到本地 ASR 设置补齐，再开始任务。

## 逐句工作流资源

字幕工作流按句处理。猫爪 API 节点中可引用“当前句子录音”作为音频附件、“句子区间中点截图”作为图片附件，选用支持对应输入的模型。普通字幕机翻不需要这些附件。选择语言/API 的入口应打开列表弹窗，语言列表最后可手动输入；纯本地流程不应出现 API 选择。

旧成果与排队任务冲突时，队列会自动清理该页并重跑；其他页面成果保留。按你确认的规则，冲突重跑也会自动重试结果未知的 API 请求，可能再次调用；暂停/取消仍应阻止后续写入。

## 播放控制

- 单击显示/隐藏控制；中间双击播放/暂停，两侧双击 ±10 秒。
- 长按临时两倍速，松开恢复；左右滑动调时间，左侧上下调窗口亮度，右侧上下调音量，验证不会串触其他手势。
- 锁定后仅能解锁，解锁后恢复操作。测试横竖切换、上/下一视频和列表。
- 右上角播放菜单测试速度、音轨、播放模式和画中画。默认普通返回暂停播放；允许后台播放/PiP 时另测恢复位置。后台翻译应独立于播放开关。

## 画面与两条分支

先选约半分钟、文字清楚的视频，采用默认 1 fps。翻译选项选“仅画面”，选择已准备好的图像工作流，提交后退出播放器；任务仍应推进，重进播放时只在对应时间显示成果。再测试“画面与字幕”：两支分别报告进度，一支缺能力不应抹掉另一支成果。

运行时点暂停，应先显示正在暂停，达到安全边界后才为已暂停；开始沿用同一个任务。单独开始一支不解除另一支暂停；“全部开始”会逐卡片开始。播放中“翻译本画面”和阅读器“翻译本页”应立即出现真实任务，优先等到下一份必要资源。

## 人工修改

- “编辑译文”只操作画面气泡：改文字、位置和该气泡自己的开始/结束时间，保存后重进检查。可分别设置两个气泡的消失时间。
- 先暂停相应任务，再从播放菜单“字幕”进入工具栏，测试原文/译文、起止时间、上一条/下一条、添加/删除和撤销，保存后重进检查。按本轮队列要求，重新启动翻译遇到已有成果冲突时会清理冲突页并重跑；编辑器自己的保存仍检查版本冲突。
- 清除译文前检查画面/字幕和时间范围选择；原视频和原字幕应保留。
- SRT、成果包的导入导出和译文版本管理按用户要求留待后续，本轮无需验收这些入口。

## 反馈方式

先发“出错入口 → 操作 → 实际提示/现象 → 预期结果”。再附视频时长/分辨率、语音语言、ASR 模型、字幕/画面工作流、前台或锁屏状态，以及截图（方便时）。无需发送私密视频或 API 密钥。识别文字错误、译文错误、时间偏移、播放卡顿请分别说明。
