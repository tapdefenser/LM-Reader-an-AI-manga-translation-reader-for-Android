## 用户已确认的语义

- 字幕识别固定使用设置中选中的本地 ASR，保留字幕翻译工作流。每句保留稳定身份、录音区间和中点原画面资源。
- 当前字幕编辑默认译文，可切换原文；前后按钮跳到相邻条目的开始时刻。
- 时间输入支持秒、分:秒、时:分:秒；缺省字段补零，空白为零。
- 本地 ASR 加速方式放在设置 → API 与翻译引擎 → 本地 ASR 模型，默认自动。
- 既有翻译队列的共同排序、升降序子菜单、嵌套章节卡片和逐卡批量开始/暂停语义继续保留。本批没有重新设计队列 UI。

## 本批实现

1. 视频选项恢复气泡、游离文字、两者三种识别范围，并传入工作流与成果语义。视觉引擎读取与漫画相同的实时全局 GPU/并发设置；本地机翻和 API 继续使用共同资源入口。
2. 字幕源逐批持久化后立即送往有界翻译队列；识别恢复点和字幕翻译计数分别保存。画面最多两份在途，允许前后采样的识别与翻译重叠。已完成采样立即保存正式成果，顺序检查点可以滞后；重复实际 PTS 共享结果。
3. 新增逐区域原画面观察，复用屏幕视频模式的几何、轮廓和原文笔画匹配。匹配到的区域保留同一译文轨并延长观察范围，不再以每张截图结束遮罩。播放器按区域时间与原画面证据读取成果。
4. 气泡编辑器使用原播放器预览、暗色可读控件、可拖动的紧凑浮动工具栏、播放/暂停及可输入的时间跳转。可同时编辑来自不同采样锚点的活动区域，以一个新人工快照原子发布，并保留原机器成果；几何锚点和人工时间覆盖分别保存。
5. 字幕编辑嵌入气泡编辑器，仅显示当前选中条目，支持原文/译文切换、前后开始时间跳转、增删、撤销、保存和单条时间校对。横屏放在播放进度区右边。编辑器跟随播放器选中的字幕源。
6. 播放菜单的字幕入口改为关闭、选择导入字幕或生成字幕；翻译菜单增加字幕显示切换。字幕样式设置移到翻译选项。播放列表改为右侧半透明抽屉，复用图库元数据与缩略图，裁成正方形。播放及翻译菜单限制高度并支持滚动。
7. 本地 ASR 接入 CPU、Vulkan、可选厂商 OpenCL 的真实原生后端。自动依次尝试 GPU，失败回退 CPU并记录原因；明确选择 GPU 时失败会说明原因。保留现有 GGML 模型格式，不另下载 GPU 权重。结束一个视频的 ASR 不再主动中止另一个视频刚获准的调用。
8. 数据库升级至 schema 2，增加小型区域观察与编辑锚点，执行非破坏迁移。备份兼容旧 schema；既有成果包接口补足新字段，未新增导入导出管理界面。

## 构建条件

ASR 源码、Vulkan/SPIR-V/OpenCL 头文件及许可证固定在 `tools/asr_sources.lock.json`。先运行 `python tools/fetch_asr_sources.py`；配置阶段不联网。GPU shader 生成需要主机 C++17 编译器，可通过 `-Plmreader.asr.hostToolchain=...` 指定。CPU 专用构建可将 `lmreader.asr.vulkan`、`lmreader.asr.opencl` 同时设为 `false`。

Android 26 的 Vulkan 1.0 加载器不能直接导入 1.1 符号；构建时对固定上游源码生成一份可审计的动态分发适配，不修改下载的上游源目录。OpenCL 使用可选厂商驱动加载器，CPU 不依赖设备存在 `libOpenCL.so`。
