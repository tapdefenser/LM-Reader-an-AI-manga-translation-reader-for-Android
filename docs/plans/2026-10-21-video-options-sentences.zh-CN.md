# 视频选项与逐句字幕调整

本轮按用户手机反馈修订已有方案。保留原包名、签名和工作区；SRT/成果包导入导出、译文版本管理不在本轮继续扩展。

- 视频选项改为竖排设置行。源/目标语言来自当前机翻目录和已安装语言包；列表弹窗末尾可以手动输入语言代码，也可以主动刷新目录。
- 画面、字幕各保留自己的翻译工作流。仅当所选分支工作流使用 API/API_STREAM 时显示该分支 API 行；点击打开列表弹窗。分支选择仍覆盖所有嵌套 API 节点的绑定。
- 字幕识别固定使用本地 ASR，模型只在“设置 → API 与翻译引擎 → 本地 ASR 模型”管理。首次只有一个已安装模型时自动采用它；视频选项不再重复选模型，也不再选择识别来源或音频转写 API。新任务捕获设置中的当前模型，断点记录其模型和字幕源身份。
- 每个有时间戳的语句是一个独立翻译单元，沿用稳定 cueId；逐句执行字幕翻译工作流、保存和恢复。没有凭标点猜造新的时间戳。
- 猫爪 TIMED_TEXT 场景增加只读的“当前句子录音”（音频类型）和“句子区间中点截图”（图片类型）。API 节点可分别引用它们作为音频、图片附件。现有字幕记录的五个字段保持兼容；本地工作流没有引用附件时不解码这些资源、不上传声音。
- 录音由原音轨对应区间按需重建为 16 kHz 单声道 PCM16 WAV；截图从原视频的区间中点解码。资源不依赖播放器的位置、速度、遮罩或字幕。录音窗口限两分钟，解码与像素许可按阶段释放。
- API 编码支持 Chat Completions 的 `input_audio` 和 Gemini 的音频 `inlineData`；当前 Responses 适配明确报告不支持音频附件。所选模型还需具备相应输入能力。依据：[OpenAI 官方音频说明](https://developers.openai.com/api/docs/guides/audio-chat-completions)、[Gemini Generate Content 音频说明](https://ai.google.dev/gemini-api/docs/generate-content/audio)。录音字节不写入请求日志。
- 队列遇到旧语义、旧身份或版本冲突时，仅清理对应页面的成果并请求自动重新执行。单页、章节和视频使用相同的执行代次/发布屏障；其他页面成果保留。暂停、取消已生效时不能由迟到结果继续清理或写入。用户进一步明确“所有冲突均自动重试”，因此冲突重跑也授权再次提交结果未知的 API 请求，可能产生重复调用；已授权重试的旧回执不会被迟到回调改回未知。这个例外只适用于成果冲突；普通失败仍单独重试，编辑器保存仍检查版本冲突。
- 字幕样式、播放音轨等保留在播放器工具内，视频翻译选项移除“准备状态”、字幕高级设置、ASR 模型和 SRT 管理。
