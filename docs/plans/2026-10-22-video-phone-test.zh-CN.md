# 0.1.12 手机试用步骤

本次先验证视频试用反馈。安装结果与自动化检查见[本批记录](2026-10-22-video-feedback.zh-CN.md)。ARM 手机上的真实识别速度、GPU 驱动兼容性及长视频后台表现需要这次试用确认。

1. **确认模型与后端。** 设置 → API 与翻译引擎 → 本地 ASR 模型，选择已经下载的 Whisper Base，推理后端先用“自动”。无需重新下载同一份模型。启动识别后查看实际加载的后端；需要比较速度时，用相同视频、语言和模型分别测试 CPU 与设备可用的 GPU 后端。
2. **用短视频重新排队。** 选择一段约 30–60 秒、有人声和画面文字的视频。翻译选项选择“画面与字幕”、源/目标语言、画面及字幕翻译工作流，确认画面范围里的“气泡 / 游离文字 / 气泡和游离文字”可选。有 API 节点的分支才显示 API 选择。提交后退出播放器，观察翻译队列：识别出的字幕应逐批进入翻译，已完成的部分可以播放查看。旧任务显示配置变化时，通过翻译选项更新并重新排队，以使用本版的区域观察记录。
3. **检查遮罩持续时间。** 找一段相同气泡停留数秒、随后改变文字或切镜头的画面。已完成译文应跨相似采样画面持续显示，在内容变化或消失时结束；拖动到另一时刻应立即清掉不属于该时刻的遮罩。播放器的显示开关无需重新翻译。
4. **检查编辑与横屏。** 打开“编辑译文”，拖动左上工具栏，使用进度条左侧播放/暂停。在当前位置输入 `5` 或 `1:20`，应分别跳到 5 秒、1 分 20 秒。点气泡修改并保存，再退出重进。下方字幕框默认译文，可切原文；左右按钮跳到相邻字幕的开始。横屏字幕框应位于进度区右侧，文字与按钮清楚可读。
5. **检查播放菜单。** 右上“字幕”用于关闭、导入或选择翻译字幕；翻译菜单可显示/关闭字幕。右下播放列表从右侧滑出，点击箭头或列表外画面收回。横屏时播放菜单和翻译菜单均可上下滑动。

若发现问题，请告知视频大致时刻、选择的工作流及 ASR 后端、操作步骤和屏幕提示；保留该任务，方便对照日志定位。GPU 是否更快要以同一片段的实际耗时判断，不能只看选项名称。
