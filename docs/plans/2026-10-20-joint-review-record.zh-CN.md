### 当时发生的取舍

| 议题 | DS 初始意见 | 最终进入审阅稿的处理 |
|---|---|---|
| 最先投入 | 先修成果正确性、首译、资源清单 | B0 先核验并处理确认的阻断，之后 B1/B2；既有改动不视为已通过 |
| 成果复用 | 目标语言/工作流没有完整校验，直接定性缺陷 | 保留静态风险，实施时复现；禁止不一致结果静默计入新任务，保护人工成果；不自动发起付费重译 |
| 阅读器样式 | 从 cached() 未使用 render 推断阅读器样式失效 | Codex 核对 ReaderScreen/ReaderImageView；DS 第二轮撤回此推论。仅将阅读与导出取值时点差异列为待确定行为 |
| 导出一致性 | 改成当前设置，或更改固定快照文案 | 推荐创建导出任务时捕获当前配置，准备阶段写固定快照；后续重试稳定；加入具体验收，用户决定捕获时点 |
| API 配置 | 全部过滤为 LLM | 现有全覆盖已有 UI 说明；不按类别一刀切。简易模板限定主翻译节点，高级全覆盖显式保留，按节点能力校验 |
| 通用框架 | 过早抽象会抹平现有漫画语义 | B3 只通过真实独立文件任务提炼契约，不重写全部队列；B4-A 可复用现有接口先交付 |
| 助手和视频 | 同时建设摊子过大 | 阅读器内解释先行；完整会话/工具工作台与视频择一重点，另一项保持有界验证 |
| 跨平台 | 当前 Android 工程不能渐进 | DS 接受绝对措辞不成立；计划区分 common 约束验证、第二平台壳与完整产品迁移。JVM 样板不代替 iOS/Web 验证 |
| 迁移文档 | 修改旧版发布记录以对应当前工作区 | 保留历史事实，新增未发布/下一版说明；已有迁移测试不代替在途队列及用户提示验收 |
| 本地大模型 | 可选，不作为首次使用前置 | 采纳；候选模型/运行时做资源及工具调用基准，再决定推荐组合 |

### 当时第二轮意见的落实

- 成果安全默认：计划 2.2 明确 B0 出口；先阻止不一致复用，不强制先建多版本数据库。
- API 作用域：计划第 3 节给出默认跟随、简易模板主翻译节点与高级全覆盖的区别。
- 发布沟通：B0 核对、B6 交付下一版本说明及在途任务迁移提示。
- 便宜的跨平台门槛：新增 B0-X；检查真实 common 候选及元数据编译，不能只证明 JVM 运行。
- 导出样式：B2 增加“改样式→创建任务→再次改样式→导出/重试/恢复”的可执行验收。
