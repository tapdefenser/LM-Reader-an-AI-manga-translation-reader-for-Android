# 视频缓存、固定轨道与选项修正

2026-10-22。基于 `f960c45`，承接 DS 已完成的改动。本记录仅涵盖本轮五项反馈，不代表原视频总方案全部验收。

## 用户确认的行为

- 视频画面输入按“API 与翻译引擎 → SEG → 预处理缓存上限”滚动准入，允许最后一份画面越过上限；完成后释放，再补下一份。
- 相似区域由后台识别、关联并延长轨道；播放器按保存的时间、位置和译文显示，不再比较播放画面的像素。
- 视频翻译选项只保存。排队、运行中的任务继续使用原配置快照，之后新建任务使用新配置。
- 视频选项提供漫画已有的识别阈值和遮罩参数。
- 字幕显示设置放在播放器“三个点 → 字幕”的来源选择列表下方。

## 实现与边界

### 画面内存与释放

`VideoTasks.frames` 在解码前向共享 `imageCacheBudget` 申请整份画面预算，通过 `VideoFrameInput` 将位图及租约交给工作流。`AndroidWorkflowHost` 借用同一租约，计入分割结果、OCR 和必要的工作副本，避免再次申请一套输入预算。完成发布或失败后立即释放，不等待前面采样点的检查点推进。

采样位置按需计算；已完成但等待顺序确认的回执有数量上限，回执不携带位图和区域采样数据。取消时先等待生产者及其子工作结束，再清理尚未交接的输入，覆盖工作协程尚未启动的情况。

图片预算和平台解码资源预算共同约束准入；高分辨率时可能在达到设置的缓存上限前等待。缓存上限也不等于整个进程的峰值内存上限，模型、native 推理及 API 编码仍有额外开销。SEG/OCR 的并发和 GPU 设置继续通过现有执行偏好读取。

可捕获的 Java `OutOfMemoryError` 在清理资源后转为 `WAITING/MEMORY`，保留已提交成果并提示降低分析分辨率或并发。此处理不能捕获 native 崩溃或系统杀进程。

### 固定轨道播放

播放器从当前时间区间读取轨道、正式成果 revision 和已保存的位置观察，不调用区域像素匹配或旧帧 proof 校验。相同成果与几何的遮罩复用准备结果；字幕智能颜色启用时仍按需采样原画面亮度。

播放器订阅当前时间窗口内的区域变化，避免每次后台提交都把整片区域历史装入界面。后台保留已有相似区域匹配和轨道延续逻辑。

### 保存与参数

新增 `VideoFrameSettings`，保存 SEG 阈值、文字检测置信度、游离文字合并距离、视频区域相似度及遮罩/字体参数。新任务捕获这些值；缺少该字段的旧任务保留原结果身份兼容规则。

`saveOptions` 只合并选项字段，保留结果代次、轨道身份和独立字幕样式。保存不创建任务、不加入书架、不更改已有任务。翻译仍由翻译入口发起。

字幕来源选择后保持弹窗打开，显示设置位于其下方，内容可滚动；横屏同样可访问。
