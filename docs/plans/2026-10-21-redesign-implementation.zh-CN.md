## R0 固定契约

- 新装默认图片；图库/书架共用一个持久 `homeMediaMode`，各自的视频搜索、筛选、排序、滚动状态独立。
- 视频库只发现系统已索引且有权限访问的媒体；初次和刷新分页查元数据，目录发现不哈希。缩略图按可见项加载。旧 SAF 引用保留，首次翻译/恢复成果再校验内容。
- 播放列表取点击时的来源快照；普通退出暂停播放，PiP/明确后台播放例外。离线翻译由应用任务宿主推进。
- 采用建议默认：中心双击播放/暂停、两侧 ±10 秒、长按 2 倍恢复原速、水平整幅约 20%；PiP；默认 1 fps，另有 0.5/2/5 fps。速度/采样档不代表性能保证。
- 采样位置按有理数媒体时间计算，记录目标与实际 PTS；最多两份在途画面。正式成果按视频源摘要、语义身份、时间和区域索引，区分无文字与未分析。
- `media-work.db` 是新增统一 Room 数据库，不改写漫画数据库。共同记录包含视频索引、水位、书架关系、配置、任务、请求回执、帧/区域/字幕时间索引。原正式成果文件继续使用。
- 任务以 UUID 实例为身份，唯一活动键用于目标幂等；执行代次和成果 revision 分开。暂停要等待安全边界，取消要使迟到发布失效；用户暂停与系统中断分别保存。
- 用户于 10 月 21 日修订队列语义：全部暂停/全部开始只是依共同顺序逐卡片执行暂停/开始，没有独立的全局暂停状态；单独开始不改变其他卡片，新任务不继承批量暂停。全部开始恢复暂停/中断项，失败另行重试。此明确要求替代 proposal 中的后台全局暂停意图。
- 本页/本画面使用真实持久交互任务，并向视觉、机翻和 API 传递同一优先级。抢占限于下一准入点，不强断 native 或重发在途付费请求。
- 请求日志与任务回执分别记录；已发送而未确认发布的请求需核对，普通“继续”不隐式重试。成果先发布再推进检查点。
- 画面编辑与字幕编辑分开；人工编辑/删除和时间修订持久化，按 revision 提交。清理范围使用半开区间，保留范围外成果。显示设置不应触发翻译重跑。
- 导出先做 SRT 和可恢复成果包；原视频、模型、凭据和可重建缓存不进入成果包。重新编码 MP4 保持独立范围。
- ASR 使用 whisper.cpp CPU 运行时及可下载/导入的校验模型目录；按用户最新要求，识别固定采用设置中的当前本地模型，字幕翻译仍使用独立工作流。选型质量、峰值资源与 ARM 性能仍需实测；只有工作流明确引用句子录音附件时才提交声音。
