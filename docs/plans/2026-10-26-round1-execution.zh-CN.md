# 第一轮实施：视频遮罩文字颜色与质量基线

依据：[项目检查与下一步安排](2026-10-26-project-review-and-next-steps.zh-CN.md)。用户追加视频颜色选项，并授权完成第一轮。基线为 `b4c3ac7`；已有检查文档改动保留。遮罩颜色与第一轮修复在 `822530c` 已通过完整 CI。后续导航调整见下文，最新提交的完整检查与本地安装记录以关联 PR 为准。

## 实际行为

- 视频翻译选项增加「遮罩文字颜色」：黑色、白色、自动（随背景亮度）。自动在每个遮罩区域按底色选择黑字或白字。
- 颜色是独立的视频显示设置，保存后应用到已有遮罩与气泡校对预览；播放器缓存包含颜色模式，修改后重新准备显示布局。原图、译文、成果身份和任务快照不变，不调用识别/翻译/API。
- 颜色与字幕轨的文字/描边样式分别管理，修改任意一方保留另一方的配置。旧视频没有颜色字段时沿用自动行为；无需数据库迁移。
- ASR 自动模式的设置、下拉说明和实际行为统一为 CPU。Vulkan/OpenCL 标为实验选项；已确认崩溃的 `24031PN0DC` 机型在选择及实际加载 Vulkan 时均被拦截，已有保存配置也不能绕过加载检查。没有据此宣称 GPU 根因已修复或其他设备已验证。
- 能力等待原因区分 ASR、机翻、视觉和 API，并保留节点提示；导航按真实缺项选择设置，不读取 `subtitleSource` 猜测。旧 `CAPABILITY` 原因进入通用引擎设置。
- 视频工作流复用共同准备检查；单页/视频的模型准备保留取消语义，能力补齐后通过原任务显式继续，仍使用原快照与安全检查点。
- 补齐英文目录和人工 overrides；CI 先运行本地化检查，再准备 SDK、源码和模型。中英 README 补 ASR 源码及主机工具链条件，使用指南补本地视频与恢复路径。
