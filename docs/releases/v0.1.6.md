# v0.1.6

## 中文

- 浏览模式在弹窗、菜单遮挡期间保留底层气泡与覆盖记录：窗口 ID 变化不再直接当作换页。系统暂时不提供底层窗口时暂停采样，弹窗关闭后接回原场景；仍能取得底图时只排除被遮挡区域。应用内绘制的局部菜单用网格纹理连续性识别，周围仍保留原图时不按匹配超时清空整页。遮挡期间暂停新增识别，已回填的译文继续保留。
- 新增区域只把实际新增裁块送入普通 SEG/DET，已有原文按同一张干净截图的光流位置切除。新检测文字与旧文字接触，或距离不超过新增的「新旧文字区域合并间距」（默认 8 截图像素，0–128 可调；设为 0 只合并接触或重叠）时，才恢复同帧完整原图重新 SEG/DET，最终区域确定后才提交 OCR。形状与原图纹理均未变化的旧文字复用现有对象，不重复 OCR／翻译。
- 三种模式都按已回填的气泡逐个更新画面，不再等整页翻译完成。旧译文保留到对应新文字到达；完整空结果、识别失败不会先删除旧译文，旧的空遮罩不会被迟到的旧结果复活。只有浏览模式提前绘制空遮罩，手动与视频在文字到达后才显示。
- 新增独立会话数据库记录待填、已填与已过时区域及其替代关系；旧区域被新 SEG 接管后只取消被替代区域的工作，已填部分立即跟随。光流跟随不逐帧写库，停止浏览或切换场景清空会话记录，可重译整屏。
- 单页失败隔离：漫画队列中一页在重试次数用尽后跳过，记录错误并释放预处理额度，继续本章其余页与后续章节。含失败页的章节在其余页结束后保留失败状态与重试入口，不把主动暂停写成已完成。整漫画 API 预处理同样略过失败页并释放其缓存额度。屏幕翻译的三种模式按页、按裁块隔离失败，已发布译文保留，可读旧区域在新结果为空且失败时重新参与跟踪。
- 引擎运行期间，屏幕设置、工作流切换、所选工作流的保存修订及其实际引用的 API 配置自动生效：保留仍需要的模型，后端变化只重建对应的 SEG 或 OCR 池，旧屏幕任务取消后自动恢复此前开启的连续翻译。主动停止引擎后，编辑设置不会自行重启，未保存的编辑草稿不执行。
- 录屏流结束时可切回干净的无障碍窗口截图，保留气泡与已加载资源；暂时缺帧、窗口切换与截图限频改为可重试的采集异常，不再中断连续翻译。诊断记录阶段、原因、来源、队列优先级与缓存状态，不记录译文内容。
- 已识别分块（含空 SEG 结果）按识别间隔用现有跟踪小图做 4×4 均匀纹理校验，不额外截图：在两张不同的稳定、可靠且无弹窗的有效帧中，至少四个位置可比较、覆盖至少 70% 的可见采样位置且其中至少 70% 明确失配，才释放该块的覆盖记录让新内容重新识别；仍匹配的气泡独立保留。整体变暗、遮挡或可见纹理不足不会直接清空整页。
- 新增区域差集按可用像素与裁块边界先归并再判断最小尺寸，默认保留 64 截图像素的边界上下文，细长 L 形曝光保持为局部裁块。跨裁块的新文字恢复同帧完整原图再 SEG，OCR 只使用最终文字区域与文字行，丢弃被替代的半截行。
- 更新简体中文／英语文案、使用说明与屏幕翻译重构记录；本地化检查新增简体中文资源完整性与占位符用例，并清理两条已失效的英文覆盖条目。

沿用原发布证书，可覆盖安装并保留漫画、工作流和译文。Android 8.0+，支持 arm64-v8a / x86_64；版本代码为 8。

## English

- Browse retains the underlying bubbles and coverage while a dialog or menu covers them: a changed window ID no longer means a new page. Sampling pauses when Android temporarily withholds the underlying window, then reconnects after the dialog closes; when the base frame stays available, only covered areas are excluded. Grid texture continuity identifies an in-window panel drawn over retained artwork, so a match timeout no longer clears the page. New recognition pauses during these occlusions while backfilled translations remain.
- Ordinary SEG/DET receives only the actual new image tiles, with existing source text removed at its tracked position in the same clean frame. Only new detected text touching old text, or within the new **New and existing text merge distance** setting (default 8 recognition screenshot pixels, 0–128; 0 merges only touching or overlapping text), restores a complete original-image crop for a second SEG/DET pass; OCR then receives the final regions. Old text whose shape and source texture are unchanged reuses its existing object without repeated OCR or translation.
- All three modes display each backfilled bubble without waiting for the page to finish. Old translations remain until their replacement text arrives; a complete empty result or a failed recognition does not delete them, and a late result cannot revive a withdrawn empty mask. Only Browse draws empty masks ahead of text; Manual and Video wait for translated text.
- A separate session database records pending, filled and obsolete regions with their replacement links. Once new SEG results take over an old region, only the superseded region's work is cancelled, and filled parts follow immediately. Optical-flow tracking does not write per frame; stopping Browse or changing scenes clears the session so the whole screen can be translated again.
- Per-page failure isolation: a page that exhausts its retries is skipped in the comic queue, recording its error and releasing its preprocessing allowance while the rest of the chapter and later chapters continue. A chapter containing failed pages keeps its error and retry entry after the remaining pages finish, and an explicit pause is no longer recorded as finished. Whole-comic API preparation also omits failed pages and releases their cache leases. The three screen modes isolate failures per page and per crop, keep published translations, and let readable old regions re-enter tracking when a merged replacement is empty and failed.
- While the engine runs, screen settings, workflow selection, saved edits to the selected workflow and its referenced API profiles apply automatically: models still needed stay loaded, a changed backend rebuilds only the corresponding SEG or OCR pool, and previously enabled continuous translation resumes after old screen tasks are cancelled. Editing settings after explicitly stopping the engine does not restart it, and unsaved editor drafts are not executed.
- Ending a recording stream falls back to clean accessibility window screenshots, retaining bubbles and loaded resources. Temporary missing frames, window transitions and capture rate limits are retryable capture conditions instead of ending continuous translation. Diagnostics record phase, reason, source, queue priority and cache state without recording translated text.
- Recognized blocks, including empty SEG results, are re-checked at the detection interval against a uniform 4×4 texture grid using existing tracking frames, with no extra capture: coverage is released only after two distinct stable, reliable, unoccluded frames where at least four comparable patches cover 70% of visible sample locations and 70% of them clearly mismatch. Matching bubbles stay; dimming, occlusion and insufficient visible texture no longer clear a whole page.
- Newly exposed rectangle remainders merge by available pixels and crop boundaries before the minimum size check, keeping 64 recognition screenshot pixels of boundary context by default, and thin L-shaped exposures stay bounded local crops. New text spanning separate crops is re-detected from one complete original-image crop; OCR uses only the final text regions and lines, discarding superseded partial lines.
- Update Chinese/English copy, the usage guides and the screen translation refactor record. The localization check now also covers Simplified Chinese resource completeness and placeholders, and two obsolete English override entries were removed.

Signed with the existing release certificate for in-place upgrades, preserving comics, workflows and translations. Android 8.0+, arm64-v8a / x86_64; version code 8.
