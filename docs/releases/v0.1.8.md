# v0.1.8

Release date / 发布日期：2026-10-14。

## 中文

- 修复多章节漫画在详情页排序后，阅读器仍按自然序组织章节的问题。阅读器现在使用详情页保存的章节顺序，包括首字母、修改时间、自然数字的正反向排序及手动拖动。
- 上一章／下一章、连续跨章、章节过渡页及相邻章节预载共用这一顺序。现有预载页数预算、章节缓存、滚动期间延迟重建与按页面身份定位的逻辑保持不变。
- 排序后继续阅读仍恢复原章节与页码；没有阅读记录时从排序后的第一章开始。封面及元数据补全继续按自然序选章。

沿用原发布证书，支持保留数据的覆盖升级。Android 8.0+，arm64-v8a / x86_64；版本 `0.1.8`，版本代码 `10`。

## English

- Fix multi-chapter comics opening in natural chapter order after reordering on the detail page. The reader now uses the saved detail-page order, including ascending and descending alphabetical, modification-time and natural-number sorting, plus manual ordering.
- Adjacent-chapter buttons, continuous reading, transitions and neighboring-chapter preloading share that order. Existing preload budgets, chapter caching, deferred rebuilds during scrolling and page-identity anchoring remain unchanged.
- Resume restores the saved chapter and page after reordering. With no saved progress, reading starts at the first chapter in the saved order. Cover and metadata selection continue using natural order.

Uses the existing release certificate for in-place upgrades preserving app data. Android 8.0+, arm64-v8a / x86_64; version `0.1.8`, version code `10`.
