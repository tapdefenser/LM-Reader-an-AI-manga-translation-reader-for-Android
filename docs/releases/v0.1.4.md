# v0.1.4

## 中文

- 猫爪列表新增只读“项数”候选；`=` 和 `+=` 前置数字、文本字面量入口，支持负数、小数及字符串。
- 新增“VL 整页直接翻译”模板：按顺序收集本页裁图，一次流式请求并逐项回填，严格校验输出项数；移除“全文速译”模板入口。
- 补齐英文工作流、后台任务、导出及备份文案，修复含嵌套表达式的动态文案提取，保留变量占位符。
- 漫画详情页的「译名管理」入口移至右上角三个点菜单，与「翻译选项」并列。
- SEG 成功后自动重建本页气泡，清空旧翻译记录、OCR 坐标与裁图缓存，更新预览；自定义输出列表和零检出同样同步本页，新旧气泡身份分开，避免旧裁图被继续使用。
- 普通与流式 API 请求的附件栏明确支持 `<图片>`／`<列表<图片>>`；变量类型增加图片列表快捷选项，多图按列表顺序发送到同一次请求，张数不限（合计 16 MB Base64 为唯一预算）。
- 游离文字按检测行重新分组，减少相邻行黏连；翻译选项增加「游离文字行间合并距离」，默认 0 为逐行独立，支持横排和竖排。重新识别／重译后生效。新建遮罩设置的默认不透明度改为 60%，保留已有设置。
- 修复扫描结束后的图库分页漏项：完整文档路径区分同名漫画，分别添加来源与单／多章节均保留各自记录。重复扫描不复制同一路径，不覆盖收藏和译名字典；已加载分页额度保留。
- 游离文字按整个检测框排版，减少留白、增大可用字号，并增加对比描边。阅读器与导出使用同一算法，已有译文无需重新调用 API。
- 启动及关于页检查更新共用更新日志弹窗，提供每次启动、每日首次启动、每三日和关闭四种频率。支持后台下载安装包、重启后恢复进度、签名与版本校验及 Android 安装入口。
- 补齐翻译、导出通知栏：分别显示漫画、章节、页数进度与未完成章节数，支持单独暂停、继续和打开对应队列；翻译保留 SEG／OCR／API 当前并发数。
- 完成、失败和暂停通知在后台服务停止后仍可查看；取消任务不会误报完成。从通知继续暂停章节时，失败章节保留为手动重试。
- Android 13 及以上首次运行任务时申请通知权限，拒绝不会中止任务；后台任务设置可再次申请或打开对应通知渠道设置。
- 本次通知更新沿用 v0.1.4（版本代码 6）和原发布证书。
- 猫爪 API 默认附带当前气泡循环项的裁图，游离文字同样作为 `<列表<气泡>>` 处理。抽屉可选择自动附图、其他图片或“不附图”，猫爪文本显示实际选择；同步、异步和复制的循环均保留各自图片身份。
- 修复无文字候选图触发“请上传图片”的回复，明确返回空对照。Chat 结构化输出按所选类型自动发送 JSON Schema，减少大段文字的非法 JSON 转义；保留用户自定义参数，对不支持的接口自动回退。
- 单页重译的 API 日志增加来源标记。HTTP 200 后输出校验失败也记录为失败，并保留模型正文、HTTP 状态和实际附件数。
- 改善无效 JSON 的错误说明，避免把模型回复中的示例对象写入译文。

使用原发布证书覆盖安装，保留漫画、工作流和已有译文。安装后重新翻译失败页即可使用修复。

## English

- Add read-only list item counts and accessible number/text literals for Cat Paw assignment and append, including negative values and decimals.
- Add direct page vision translation with ordered image collection, one streaming request and strict result-count validation. Remove the full-comic fast translation template from built-in and editor choices.
- Complete English workflow, background-task, export and backup copy, and preserve placeholders when extracting Kotlin strings containing nested expressions.
- Move Translation Management from translation options to the comic details overflow menu.
- Successful SEG replaces the page's bubbles, clears stale page records, OCR coordinates and crop caches, and refreshes previews. Custom output lists and empty detections also synchronize the page; new region identities invalidate old crop references.
- Ordinary and streaming API steps expose both image and image-list attachments. A direct image-list variable type simplifies collection; each request sends all list images in order with no image count limit (the combined 16 MB Base64 budget still applies).
- Regroup free text by detected lines to separate nearby rows and columns. Translation options add a per-comic line merge distance, defaulting to 0 for independent lines; recognize/retranslate to apply it. New mask settings default to 60% opacity while existing settings are retained.
- Reconcile the loaded library window after scanning, preserving separate same-title comics at different paths in single/multi-chapter modes and separate sources. Rescans retain existing IDs, shelf membership and glossaries without duplicating the same path or resetting the paging quota.
- Free text uses its entire detection frame with less padding, larger fitted fonts and contrasting outlines. Reader and export share the layout; saved translations do not need another API request.
- Startup and About share a release-notes dialog, with every-launch, daily, three-day and off frequencies. APK downloads continue in the background and recover after reopening, with package/version/signature verification and the Android install flow.
- Separate translation and export notifications show manga, chapter, page progress and unfinished chapters, with independent pause/resume controls and queue links. Translation also retains active SEG/OCR/API counts.
- Paused, completed and failed notifications remain after the background service stops. Cancellation does not imply completion, and notification resume preserves failed chapters for explicit retry.
- Android 13+ requests notification permission when the first task runs. Denial does not stop tasks; background-task settings provide permission and channel controls.
- This notification update keeps v0.1.4 (version code 6) and the existing release certificate.
- Automatically attach the current bubble iterator crop to Cat Paw API steps, including free text. Explicit images and **No image** override the default. Sync, async and copied loops preserve each item's identity.
- Return empty pairs for unreadable candidates and derive native Chat JSON Schema from the selected output type. Preserve custom response parameters and fall back when a server explicitly rejects structured output.
- Label single-page retranslations in API logs and retain output-validation failures, attachment counts and original responses after HTTP 200.
- Explain invalid JSON clearly without extracting model examples as translations.

Signed with the existing release certificate for an in-place upgrade. Retranslate failed pages to apply the fix.
