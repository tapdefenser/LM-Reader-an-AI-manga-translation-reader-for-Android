# v0.1.10

Release date / 发布日期：2026-10-18。

## 中文

- 屏幕翻译模式长按翻译球可打开翻译设置，并提供震动反馈；拖动或取消手势不会误触长按。
- 阅读器页码移除半透明背景底片，只保留页码文字。
- 主菜单支持上下滑动，横屏也可访问底部的设置等全部选项。

沿用原发布证书，支持保留数据的覆盖升级。Android 8.0+，arm64-v8a / x86_64；版本 `0.1.10`，版本代码 `12`。

## English

- Long-press the screen-translation ball to open translation settings with haptic feedback. Dragging or cancelling the gesture does not trigger a long press.
- Remove the translucent background behind the reader's page counter, leaving only the text.
- Make the main menu vertically scrollable so every destination remains accessible in landscape.

Uses the existing release certificate for in-place upgrades preserving app data. Android 8.0+, arm64-v8a / x86_64; version `0.1.10`, version code `12`.

## 验证与边界 / Verification and limits

- 已完成本轮定向 JVM 单测与 MuMu Android 15 长按手势验证；横屏菜单验证覆盖滚到底部、返回顶部及点击设置。
- Targeted JVM tests and ball-gesture checks passed on MuMu Android 15. Landscape-menu checks cover reaching the bottom, returning to the top and opening settings.
- 发布附件 `release-metadata.json` 与 `SHA256SUMS` 记录正式 APK 的源提交、版本、签名指纹与校验值。ARM 长时后台、真实云提供方及既有分发审查待办仍保留，详见 [v0.1.7 发行说明](v0.1.7.md)。
- Attached `release-metadata.json` and `SHA256SUMS` record the release APK's source commit, version, signing certificate and checksums. Prolonged ARM background, real cloud-provider and existing distribution-review checks remain open; see the [v0.1.7 notes](v0.1.7.md).
