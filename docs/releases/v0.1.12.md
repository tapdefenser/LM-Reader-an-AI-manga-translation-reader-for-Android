# v0.1.12

本地试用修复版 · 2026-10-22 · Android 8.0+ · arm64-v8a / x86_64 · 版本代码 14。

- 视频翻译选项恢复气泡/游离文字范围，复用漫画的全局引擎资源配置。
- 字幕识别逐批送入翻译工作流；画面使用两份在途窗口，按区域相似性保留遮罩及正式成果。
- 气泡编辑器增加播放暂停、简写时间跳转、可拖动浮动工具栏，以及当前字幕原文/译文校对。横屏字幕编辑区放在播放进度右侧。
- 播放器字幕菜单选择关闭、导入或生成字幕；字幕样式放入翻译选项，播放列表使用右侧半透明抽屉，菜单支持滚动。
- 本地 ASR 增加自动、CPU、Vulkan、可选 OpenCL，显示设备能力及实际后端；GPU 是否更快仍需目标设备实测。现有模型权重可继续使用。
- 旧视频数据执行非破坏升级，沿用原发布证书覆盖安装，保留应用数据。

本版不表示原视频改造计划全部验收完成。定向验证与手机交付结果记在[本批记录](../plans/2026-10-22-video-feedback.zh-CN.md)；原有分发审查待办继续保留。
