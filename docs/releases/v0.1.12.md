# v0.1.12

发布日期 / Release date：2026-10-23。Android 8.0+ · arm64-v8a / x86_64 · 版本代码 / version code 14。

## 中文

- 图库与书架支持视频，使用共用的图片/视频切换；视频播放器、播放列表、手势、字幕选择与气泡编辑整合到观看流程。
- 视频画面和字幕通过翻译队列在后台处理。画面预载受 SEG 预处理缓存预算控制，消费后释放像素，避免按整片视频累积所有采样图片。
- 画面翻译按相似区域延续已保存的气泡轨道；播放器按时间读取正式轨道，不在播放时重复比对或运行识别。
- 视频翻译选项恢复气泡/游离文字范围，新增“响应与区域”：采样间隔、区域相似度、截图最长边、区域上下文与识别区上下缘。保存只更新下次任务，已有任务保持原配置。
- 漫画、单页、屏幕和视频共用工作流资源需求计算：分块范围决定 SEG/DET，后续 OCR、机翻节点决定额外模型；保留其他任务仍需要的模型，差异卸载空闲资源。自定义 SEG/OCR 并行数作为跨任务全局上限，自动模式继续按设备资源决定。
- 翻译队列中的视频与漫画共同排序和移动，漫画保留章节卡片；批量暂停/开始作用于各任务，完成和取消的任务自动出队。启动时队列默认暂停，继续由用户手动发起。
- 字幕识别逐句送入字幕翻译工作流，每句可提供对应录音和中点截图资源；识别使用设置中选定的本地 ASR 模型。
- 气泡编辑器增加播放暂停、简写时间跳转、可拖动浮动工具栏，以及当前字幕原文/译文校对；横屏字幕编辑区放在播放进度右侧。
- 播放器字幕菜单选择关闭、导入或生成字幕，字幕显示设置放在该菜单下方；播放列表使用右侧半透明抽屉，菜单支持滚动。
- 本地 ASR 提供自动、CPU、Vulkan 与可选 OpenCL，并显示设备能力及实际后端。自动模式使用 CPU；GPU 需手动选择，兼容性和速度仍需目标设备实测。现有模型权重可继续使用。
- 旧视频数据非破坏升级，沿用原发布证书，支持保留应用数据的覆盖安装。

## English

- Add video browsing to the gallery and shelf, with a shared image/video switch and an integrated player, playlist, gestures, subtitle selection and bubble editor.
- Run frame and subtitle translation through the background translation queue. Frame preloading follows the SEG preprocessing cache budget and releases consumed pixels instead of retaining an entire video's sampled images.
- Extend saved region tracks while source regions remain similar. Playback reads these tracks by timestamp without running recognition or frame matching.
- Add response and region options: sampling interval, region similarity, analysis size, crop context, and top/bottom recognition limits. Saving updates future tasks while existing tasks retain their configuration snapshots.
- Share workflow model-demand planning across comics, individual pages, screen translation and video. Block scope controls SEG/DET; later OCR and translation nodes determine additional models. Keep resources needed by other owners, unload unused idle resources, and enforce configured SEG/OCR concurrency as global per-resource limits.
- Keep comic chapter cards and a common ordering for comic/video translation tasks. Batch pause/start acts on individual tasks; completed and cancelled tasks leave the queue. Queues start paused after app launch.
- Stream recognized sentences into the subtitle translation workflow, with optional sentence audio and midpoint screenshot resources. Recognition uses the local ASR model selected in settings.
- Improve bubble/subtitle editing with play/pause, shorthand time input, a draggable floating toolbar and compact landscape controls. Add a translucent side playlist and scrollable player menus.
- Offer automatic, CPU, Vulkan and optional OpenCL ASR backends. Automatic mode uses CPU; GPU compatibility and performance require device testing.
- Preserve the original release certificate and support in-place upgrades retaining app data.

## 验证与边界 / Verification and limits

本次发布复用 10 月 22 日 22:08 已安装到 Android 16 ARM64 手机的原签名 APK，文件完全一致。该包完成 Release 构建、签名与保留数据的覆盖安装、摘要核对和启动检查；最后一批“响应与区域”改动未另做设备功能回归。此前资源专项的 27 项 JVM 与 14 项设备测试通过。不能据此宣称所有视频模式、GPU 或长视频已全面验收。

This release reuses the exact signed APK installed on an Android 16 ARM64 phone on October 22. Release compilation, signing, in-place installation, installed-APK checksum and launch checks passed. The final response/region changes did not receive a separate device functional regression. Earlier shared-resource checks passed 27 JVM and 14 device tests; these do not establish complete long-video or GPU validation.

本版不表示原视频改造计划全部完成。ARM 长时后台、ASR GPU 性能、真实云提供方、项目许可证选择、SEG 权重分发依据和完整依赖审查仍沿用已有待办。详见[本批记录](../plans/2026-10-22-video-feedback.zh-CN.md)与[共享资源记录](../plans/2026-10-22-shared-vision-demand.zh-CN.md)。字幕/成果包等未完成路线不作为本版完成承诺。
