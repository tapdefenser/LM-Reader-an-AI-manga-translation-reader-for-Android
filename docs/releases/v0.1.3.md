# v0.1.3

## 中文

- 修复粗体、描边和竖排文字的区域分组：合并整段文字与局部预测，保留完整检测行，避免同一气泡被重复拆分或文字被裁掉。默认检测阈值保持不变。
- 翻译、导出队列为空时，加入新任务自动启动，清除上一批手动暂停；有未完成任务时继续保留暂停状态。
- 阅读方向、屏幕方向及其他阅读设置统一全局生效，旧漫画专属覆盖不再参与阅读设置。
- 修复裁白边和重新绑定图片源后译文遮罩消失的问题。空译文区域可在编辑模式中圈选，普通阅读与导出继续保留原文。
- 无效工作流快照显示失败并让其他任务继续，避免队列反复处理同一无效任务。

使用原发布证书，可覆盖安装。已有译文数据保留；重新翻译页面可使用新的检测和分组结果。

## English

- Merge overlapping text predictions before splitting balloons, and retain complete detected lines for heavy, outlined and vertical lettering.
- Start new batches automatically when an empty translation or export queue receives tasks after a previous manual pause. Preserve pauses on occupied queues.
- Apply all reader preferences globally and ignore legacy manga-specific reader overrides.
- Restore overlays after cropped-image rebinding. Keep untranslated regions selectable while editing without covering their original text.
- Fail unsupported workflow snapshots instead of repeatedly selecting the same invalid task.

The existing release signing certificate supports in-place upgrades. Saved translations remain available; retranslate a page to apply the new region detection.

## 验证 / Verification

- 175 JVM unit tests passed.
- 37 instrumentation tests passed across MuMu Android 15 and the Android 16 phone, including the two original pages, local OCR and vision API workflow paths, queue admission, global settings and overlay rendering.
- Release build and lint passed with no lint errors. Existing warning categories remain.
- Signing, model checksums, native JNI types, 64-bit ABI and 16 KB alignment are verified by the release packaging tool.
