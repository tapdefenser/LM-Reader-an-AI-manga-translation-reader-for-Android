# v0.1.9

Release date / 发布日期：2026-10-14。

## 中文

- 修复屏幕翻译视频模式无法持续处理的问题。最多缓冲两张截图；一帧的全部选区完成 SEG 后才允许下一次截图，队首完成翻译回填才释放缓冲容量。后帧提前完成不会绕过队首持续提交截图。
- 截图延时从前一帧的 SEG 完成开始计算，与下一帧的 SEG 重叠。SEG 较快时等待剩余延时，较慢时等待 SEG 完成；始终还要满足双帧容量和缓存限制。
- 新增独立的“视频 SEG 区域相似度”，默认 60%。比较对应区域的 SEG 形状与原文纹理，相似时移除新区域，沿用原气泡和译文，尚未完成的翻译也会回填到新位置。
- 新气泡填出译文前保留旧译文；选区独立处理，单个选区失败仍保留重试输入。手动、浏览模式及漫画阅读器的章节预载逻辑保持原有行为。

沿用原发布证书，支持保留数据的覆盖升级。Android 8.0+，arm64-v8a / x86_64；版本 `0.1.9`，版本代码 `11`。

## English

- Fix continuous screen translation in video mode. At most two captures are buffered. All selected areas must finish SEG before the next capture; only completion of the oldest frame's translation and backfill releases capacity. A newer frame finishing early cannot create an unbounded capture queue.
- Count capture delay from the preceding frame's SEG completion, overlapping the next SEG pass. Fast SEG waits out the remaining delay; slow SEG waits for completion. Buffer capacity and cache limits always apply.
- Add independent video SEG-region similarity, defaulting to 60%. Compare corresponding SEG shapes and source-text texture, discard duplicate detections and retain existing bubbles and text. Pending translations follow the retained bubble to its new location.
- Keep old translations until replacement text is filled. Process selected areas independently and retain failed inputs for retry. Manual, browse and reader chapter-preload behavior remain unchanged.

Uses the existing release certificate for in-place upgrades preserving app data. Android 8.0+, arm64-v8a / x86_64; version `0.1.9`, version code `11`.
