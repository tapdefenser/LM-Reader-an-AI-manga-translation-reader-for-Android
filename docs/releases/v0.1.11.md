# v0.1.11

Release date / 发布日期：2026-10-19。

## 中文

- 新增“OPUS-MT 本地机翻”可选工作流，与现有 Bergamot 分开选择，任务快照保留引擎绑定。
- OPUS-MT 模型页首次进入或缓存超过一天时自动获取兼容语言包列表，也支持手动刷新；刷新失败保留旧目录。初始备用目录收录 64 个方向，其中 21 个为非英语直达方向。
- 优先使用已安装的直达模型，否则寻找经任意已安装语言的最短中转路径，最多三段，不限定英语。每个完整方向包不超过 350 MB，权重按需下载，不随 APK 打包。
- 复用现有 ONNX Runtime 与 SentencePiece。当前 OPUS-MT 使用 CPU；QNN／NNAPI 尚未启用。具体速度和质量取决于模型、方向与设备。
- 应用外从通知入口或长按翻译球打开设置时，弹窗保持在应用外，不再拉起 LM-Reader 主界面。
- 清理已停用的本地翻译后端、下载源、代码和资源。

沿用原发布证书，支持保留数据的覆盖升级。Android 8.0+，arm64-v8a / x86_64；版本 `0.1.11`，版本代码 `13`。

## English

- Add an optional OPUS-MT local workflow alongside Bergamot. Queued task snapshots retain their explicit engine binding.
- Automatically discover compatible OPUS-MT packages on first visit or when the catalog is over a day old, with manual refresh and preservation of the usable catalog on failure. The initial offline fallback lists 64 directions, including 21 direct non-English directions.
- Prefer installed direct models, otherwise choose the shortest path through any installed language, capped at three model stages. English is not required. Each complete direction package is capped at 350 MB; weights are downloaded on demand and are not bundled in the APK.
- Reuse the existing ONNX Runtime and SentencePiece libraries. OPUS-MT currently uses CPU; QNN/NNAPI acceleration is not enabled. Speed and quality depend on the model, direction and device.
- Open screen-translation settings from notifications or a ball long press without bringing the reader's main task to the foreground.
- Remove the retired local translation backend, download sources, code and resources.

Uses the existing release certificate for in-place upgrades preserving app data. Android 8.0+, arm64-v8a / x86_64; version `0.1.11`, version code `13`.

## 验证与边界 / Verification and limits

- 定向 JVM 单测 235 项及本地化工具 6 项通过；MuMu Android 15 实际模型验证覆盖法语→德语直达、日语→英语→中文中转、取消后重试、模型保留和释放。应用外通知及长按设置入口已完成独立设备验证。
- 235 targeted JVM tests and six localization checks passed. Real-model checks on MuMu Android 15 cover direct French→German translation, Japanese→English→Simplified Chinese routing, cancellation recovery and model retention/release. External settings entry points have separate device verification.
- 正式附件使用原签名证书，并记录版本、源提交、签名指纹、JNI 绑定、16 KB 对齐与校验值；正式版安装及运行验收记录随本轮构建保存。
- Release assets retain the original signing certificate and record the version, source revision, certificate fingerprint, JNI bindings, 16 KB alignment and checksums. Signed-build installation and runtime acceptance evidence is retained with this release run.
- QNN／NNAPI 与 ARM 长时后台未作为本版已验证能力；真实云提供方及既有分发审查待办仍保留，详见 [v0.1.7 发行说明](v0.1.7.md)。
- QNN/NNAPI acceleration and prolonged ARM background execution are not validated capabilities of this release. Real cloud-provider and existing distribution-review checks remain open; see the [v0.1.7 notes](v0.1.7.md).
