# v0.1.5

## 中文

- 翻译队列默认采用「资源利用优先」，可切换为「队列顺序优先」。SEG、OCR、机翻和 API 分别限流；不同 API 与本地机翻可以同时推进，同一 API 共用并发额度。任一 API 步骤等待时检查后续漫画，没有可接入的任务时预处理本漫画后续页；多 API 工作流按当前等待的步骤调度。
- 未提交的 SEG／OCR 结果完整保留，包含所有气泡、游离文字检测框和 OCR 原文。一页结果可超过缓存预算，只阻塞下一页 SEG；失败和重启后仍可复用。缓存等待统一检查所有漫画及其消费者，无法继续推进时明确提示增加缓存或改用逐页／分批工作流，避免无限等待。
- 修复猫爪异步步骤的资源占用和缓存复用，自动并行数按整个模块的资源额度及共享缓存计算。API 仅在实际请求时占用并发许可，退避时释放；取消、认证失败、部分流式输出和输出校验失败不会自动重发，避免 API 与工作流重试叠加。
- 含 API 的工作流增加「本漫画使用的 API」选择，可跟随各步骤默认配置，或用一个 API 覆盖全部 API 步骤。API 工作流的语言列表优先显示已安装离线包支持的直接／中转路线；本地机翻提供离线包下载入口。
- 新设定默认值为 SEG 判定 35%、文字检测置信度 35%、游离文字合并 45%、遮盖不透明度 85%、文字边距 7%；保留已有自定义设置。
- 详情页「翻译选项」移至菜单末尾，「译名管理」位于倒数第三项。章节移除「图片目录」说明，并同步翻译页数及失败状态；漫画介绍支持长按选择、复制，长介绍可展开后复制全文。
- 书架和图库底部显示当前翻译信息栏，点击打开队列；通知标题增加阶段、漫画、章节和页数进度。
- 阅读器气泡编辑支持移动、缩放、旋转、A+／A− 调整字号、新建气泡、撤销及保存。未翻译页也可新建气泡，阅读与导出使用相同结果。修复逆向翻页时译文消失的问题。
- 书架和图库增加可拖动浮球，展开提供「屏幕翻译设置」占位弹窗，供后续功能使用。
- 更新简体中文／英语文案、使用说明和猫爪工作流说明；数据库升级至 15，兼容旧备份的新增可选字段，并修复不同应用目录间的设置存储隔离。

沿用原发布证书，可覆盖安装并保留漫画、工作流和译文。Android 8.0+，支持 arm64-v8a / x86_64；版本代码为 7。

## English

- Translation queues default to **Resource utilization priority**, with **Queue order priority** available in the menu. SEG, OCR, local translation and API requests use separate limits. Different APIs and local translation can progress together; comics using the same API share its allowance. Waiting at any API step admits eligible later comics, or preprocesses subsequent pages of the current comic when none can enter. Workflows with multiple APIs are scheduled by the step actually waiting.
- Preserve complete uncommitted SEG/OCR results, including every bubble, free-text detection and recognized text. An admitted page may exceed the cache budget; only the next SEG admission waits. Failures and restarts retain reusable results. A common dependency check examines all comics and consumers, reporting an actionable cache block when no progress is possible instead of waiting indefinitely.
- Improve Cat Paw async resource use and cache reuse. Automatic concurrency accounts for resources throughout the module and the shared cache. API permits cover actual requests and are released during backoff. Cancellation, authentication errors, partial streaming output and invalid output are not automatically replayed; workflow retries no longer multiply API retries.
- API workflows offer a per-comic API selection: follow each step's default or override every API step. Language lists prioritize direct and pivot routes supported by installed offline packs. Local translation includes an offline-pack download shortcut.
- New defaults: SEG threshold 35%, text detection confidence 35%, free-text merge distance 45%, mask opacity 85% and text padding 7%. Existing custom settings are retained.
- Move **Translation options** to the end of the details menu and glossary management to third from last. Chapter subtitles omit the image-folder label and reflect queue progress and failures. Long-press a comic description to select and copy text; expand long descriptions to copy the full text.
- Show current translation progress at the bottom of Shelf and Library, with a queue shortcut. Notification titles include the phase, comic, chapter and page progress.
- Bubble editing supports movement, resizing, rotation, A+/A− font sizing, new bubbles, undo and saving, including untranslated pages. Reader and export share the saved result. Fix translations disappearing while paging backwards.
- Add a draggable floating button on Shelf and Library. Its **Screen translation settings** entry opens a placeholder dialog for future functionality.
- Update Chinese/English copy and user/workflow documentation. Database version 15 supports the new optional fields when restoring older backups, and preferences remain isolated across different application directories.

Signed with the existing release certificate for in-place upgrades, preserving comics, workflows and translations. Android 8.0+, arm64-v8a / x86_64; version code 7.
